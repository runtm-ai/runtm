---
title: "Token Exchange"
api: "POST /api/sessions/{session_id}/ws-token"
description: "Exchange an API key for a short-lived WebSocket token"
---

Creates a short-lived JWT that authenticates a WebSocket connection. The token is scoped to a single session and capability. Tokens expire after 5 minutes - request a new one if the connection drops.

**Required scope:** depends on the requested capability:

| Capability | Required scope |
|-----------|----------------|
| `terminal` | `sessions:terminal` |
| `prompt` | `sessions:prompt` |
| `collaborate` | `sessions:read` |

## Path Parameters

<ParamField path="session_id" type="string" required>
  The session ID to connect to (e.g. `ses_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_sk_live_abc123...`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Scope to an organization.
</ParamField>

## Body

<ParamField body="capability" type="string" required>
  The WebSocket channel to authenticate for: `terminal`, `prompt`, or `collaborate`.
</ParamField>

## Response

<ResponseField name="token" type="string">
  Short-lived JWT for WebSocket authentication. Pass as the `token` query parameter when connecting.
</ResponseField>

<ResponseField name="expires_at" type="string">
  ISO 8601 timestamp when the token expires.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/sessions/ses_abc123/ws-token" \
  -H "Authorization: Bearer runtm_sk_live_abc123..." \
  -H "Content-Type: application/json" \
  -d '{"capability": "terminal"}'
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/sessions/ses_abc123/ws-token",
    headers={
        "Authorization": "Bearer runtm_sk_live_abc123...",
        "Content-Type": "application/json",
    },
    json={"capability": "terminal"},
)

data = response.json()
ws_url = f"wss://app.runtm.com/api/sessions/ses_abc123/terminal?token={data['token']}"
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/sessions/ses_abc123/ws-token",
  {
    method: "POST",
    headers: {
      "Authorization": "Bearer runtm_sk_live_abc123...",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ capability: "terminal" }),
  }
);

const { token, expires_at } = await response.json();
const ws = new WebSocket(
  `wss://app.runtm.com/api/sessions/ses_abc123/terminal?token=${token}`
);
```
</RequestExample>

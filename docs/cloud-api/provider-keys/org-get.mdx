---
title: "Get Org Provider Key"
api: "GET /api/organizations/{org_id}/provider-keys/{provider}"
description: "Check whether an organization has a provider key configured."
---

Returns the connection status and masked preview for a specific provider key belonging to an organization.

**Required scope:** `integrations:read`

<Note>The `X-Organization-Id` header must match the `org_id` path parameter.</Note>

<ParamField path="org_id" type="string" required>
  The organization ID.
</ParamField>

<ParamField path="provider" type="string" required>
  The provider name. One of: `anthropic`, `openai`, `cursor`, `devin`, `gemini`, `copilot`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token. `Authorization: Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  Must match the `org_id` path parameter.
</ParamField>

<ResponseField name="provider" type="string">
  The provider name.
</ResponseField>

<ResponseField name="connected" type="boolean">
  Whether a key is currently configured.
</ResponseField>

<ResponseField name="key_preview" type="string">
  Masked key preview. Null if no key is set.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the last update. Null if no key is set.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/organizations/org_abc123/provider-keys/anthropic" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

org_id = "org_abc123"
provider = "anthropic"

resp = requests.get(
    f"https://app.runtm.com/api/organizations/{org_id}/provider-keys/{provider}",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": org_id,
    },
)
print(resp.json())
```


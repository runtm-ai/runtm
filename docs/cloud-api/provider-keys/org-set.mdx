---
title: "Set Org Provider Key"
api: "PUT /api/organizations/{org_id}/provider-keys/{provider}"
description: "Store or replace a provider API key for an organization."
---

Stores a provider API key at the organization level. If a key already exists for this provider, it is replaced. The `policy` field controls whether this key is enforced for all members or offered as an optional fallback.

**Required scope:** `integrations:write`

<Note>The `X-Organization-Id` header must match the `org_id` path parameter.</Note>

<ParamField path="org_id" type="string" required>
  The organization ID.
</ParamField>

<ParamField path="provider" type="string" required>
  The provider name. One of: `anthropic`, `openai`, `cursor`, `devin`, `gemini`, `copilot`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token. `Authorization: Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  Must match the `org_id` path parameter.
</ParamField>

<ParamField body="api_key" type="string" required>
  The provider API key. Minimum 8 characters.
</ParamField>

<ParamField body="policy" type="string" required>
  Key policy. `enforced` overrides user keys; `optional` serves as a fallback.
</ParamField>

<ResponseField name="provider" type="string">
  The provider name.
</ResponseField>

<ResponseField name="connected" type="boolean">
  Always `true` after a successful set.
</ResponseField>

<ResponseField name="key_preview" type="string">
  Masked key preview.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the update.
</ResponseField>

<RequestExample>
```bash cURL
curl -X PUT "https://app.runtm.com/api/organizations/org_abc123/provider-keys/anthropic" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123" \
  -H "Content-Type: application/json" \
  -d '{
    "api_key": "sk-ant-api03-org-key-here",
    "policy": "enforced"
  }'
```

```python Python
import requests

org_id = "org_abc123"
provider = "anthropic"

resp = requests.put(
    f"https://app.runtm.com/api/organizations/{org_id}/provider-keys/{provider}",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": org_id,
        "Content-Type": "application/json",
    },
    json={
        "api_key": "sk-ant-api03-org-key-here",
        "policy": "enforced",
    },
)
print(resp.json())
```

```javascript JavaScript
const orgId = "org_abc123";
const provider = "anthropic";

const resp = await fetch(
  `https://app.runtm.com/api/organizations/${orgId}/provider-keys/${provider}`,
  {
    method: "PUT",
    headers: {
      Authorization: "Bearer runtm_xxx",
      "X-Organization-Id": orgId,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      api_key: "sk-ant-api03-org-key-here",
      policy: "enforced",
    }),
  }
);
const data = await resp.json();
```

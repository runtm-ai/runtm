---
title: "Team Activity"
api: "GET /api/sessions/telemetry/team/activity"
description: "Org-wide daily activity feed (GitHub-style grid data)."
---

Returns daily activity data aggregated across all members of the organization, suitable for rendering a GitHub-style contribution grid.

**Required scope:** `activity:read`

<Note>Requires organization context via the `X-Organization-Id` header.</Note>

<ParamField query="days" type="integer" default="90">
  Number of days to look back. Range: 1–365.
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  The organization to get team activity for.
</ParamField>

<ResponseField name="daily_activity" type="DailyActivityItem[]" required>
  Array of daily activity entries aggregated across all team members.
</ResponseField>

<ResponseField name="daily_activity[].date" type="string">
  ISO 8601 date (`YYYY-MM-DD`).
</ResponseField>

<ResponseField name="daily_activity[].sessions" type="integer" required>
  Total sessions created by all members on this day.
</ResponseField>

<ResponseField name="daily_activity[].prompts" type="integer" required>
  Total prompts sent by all members on this day.
</ResponseField>

<ResponseField name="daily_activity[].cost_usd" type="number" required>
  Total cost in USD across all members for this day.
</ResponseField>

<ResponseField name="period_days" type="integer" required>
  Number of days covered.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/cloud/sessions/telemetry/team/activity?days=30" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

resp = requests.get(
    "https://app.runtm.com/api/cloud/sessions/telemetry/team/activity",
    params={"days": 30},
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)
print(resp.json())
```

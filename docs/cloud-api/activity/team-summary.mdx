---
title: "Team Summary"
api: "GET /api/sessions/telemetry/team/summary"
description: "Org-wide aggregated usage summary (sessions, prompts, tokens, cost)."
---

Returns an aggregated activity summary across all members of the organization. Includes total sessions, prompts, cost, token counts, per-model breakdown, and averages.

**Required scope:** `activity:read`

<Note>Requires organization context via the `X-Organization-Id` header.</Note>

<ParamField query="days" type="integer" default="30">
  Number of days to look back. Range: 1–365.
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  The organization to get team summary for.
</ParamField>

<ResponseField name="total_sessions" type="integer" required>
  Total sessions created by all members.
</ResponseField>

<ResponseField name="total_prompts" type="integer" required>
  Total prompts sent by all members.
</ResponseField>

<ResponseField name="total_cost_usd" type="number" required>
  Total cost in USD across the org.
</ResponseField>

<ResponseField name="total_members" type="integer" required>
  Number of active members in the period.
</ResponseField>

<ResponseField name="avg_cost_per_session" type="number" required>
  Average cost per session.
</ResponseField>

<ResponseField name="avg_cost_per_member" type="number" required>
  Average cost per member.
</ResponseField>

<ResponseField name="avg_cost_per_prompt" type="number" required>
  Average cost per prompt.
</ResponseField>

<ResponseField name="avg_prompt_duration_ms" type="number" required>
  Average prompt duration in milliseconds.
</ResponseField>

<ResponseField name="total_tokens" type="integer" required>
  Total tokens consumed.
</ResponseField>

<ResponseField name="model_breakdown" type="object">
  Per-model usage stats. Keys are model names, values contain `count`, `cost_usd`, `input_tokens`, `output_tokens`.
</ResponseField>

<ResponseField name="period_days" type="integer" required>
  Number of days covered.
</ResponseField>

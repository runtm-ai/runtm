---
title: "Session Usage"
api: "GET /api/sessions/{session_id}/usage"
description: "Usage breakdown for a specific session (prompts, tokens, cost)."
---

Returns a prompt-by-prompt usage breakdown for a specific session, including per-prompt cost, model, and token counts.

In organization context, any org member can view usage for sessions belonging to that org.

**Required scope:** `activity:read`

<ParamField path="session_id" type="string" required>
  The session ID to get usage for.
</ParamField>

<ResponseField name="session_id" type="string" required>
  The session ID.
</ResponseField>

<ResponseField name="prompts" type="object[]" required>
  Array of per-prompt usage entries. Each contains fields like `model`, `cost_usd`, `input_tokens`, `output_tokens`, `duration_ms`, `timestamp`, and `prompt_preview`.
</ResponseField>

<ResponseField name="total_prompts" type="integer" required>
  Total number of prompts in this session.
</ResponseField>

<ResponseField name="total_cost_usd" type="number" required>
  Total cost for the session in USD.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/cloud/sessions/ses_abc123/usage" \
  -H "Authorization: Bearer runtm_xxx"
```

```python Python
import requests

session_id = "ses_abc123"

resp = requests.get(
    f"https://app.runtm.com/api/cloud/sessions/{session_id}/usage",
    headers={"Authorization": "Bearer runtm_xxx"},
)
print(resp.json())
```

```javascript JavaScript
const sessionId = "ses_abc123";

  {

```

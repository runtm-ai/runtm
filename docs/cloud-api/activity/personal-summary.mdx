---
title: "Personal Summary"
api: "GET /api/sessions/telemetry/summary"
description: "Aggregated usage stats (sessions, prompts, tokens, cost) for the current user."
---

Returns an aggregated activity summary for the authenticated user's dashboard. Includes total sessions, prompts, cost, token counts, per-model breakdown, and averages.

When `X-Organization-Id` is provided, only activity within that organization is included.

**Required scope:** `activity:read`

<ParamField query="days" type="integer" default="30">
  Number of days to look back. Range: 1–365.
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Optional. Scope results to a specific organization.
</ParamField>

<ResponseField name="total_sessions" type="integer" required>
  Total sessions created in the period.
</ResponseField>

<ResponseField name="total_prompts" type="integer" required>
  Total prompts sent in the period.
</ResponseField>

<ResponseField name="total_cost_usd" type="number" required>
  Total cost in USD.
</ResponseField>

<ResponseField name="avg_cost_per_session" type="number" required>
  Average cost per session.
</ResponseField>

<ResponseField name="avg_cost_per_prompt" type="number" required>
  Average cost per prompt.
</ResponseField>

<ResponseField name="avg_prompt_duration_ms" type="number" required>
  Average prompt duration in milliseconds.
</ResponseField>

<ResponseField name="model_breakdown" type="object" required>
  Per-model usage stats. Keys are model names, values contain `count`, `cost_usd`, `input_tokens`, `output_tokens`.
</ResponseField>

<ResponseField name="total_tokens" type="integer" required>
  Total tokens consumed.
</ResponseField>

<ResponseField name="total_input_tokens" type="integer" required>
  Total input tokens.
</ResponseField>

<ResponseField name="total_output_tokens" type="integer" required>
  Total output tokens.
</ResponseField>

<ResponseField name="plan_mode_prompts" type="integer" required>
  Number of prompts run in plan mode.
</ResponseField>

<ResponseField name="period_days" type="integer" required>
  Number of days covered.
</ResponseField>

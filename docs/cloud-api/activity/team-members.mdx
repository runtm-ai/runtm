---
title: "Team Members"
api: "GET /api/sessions/telemetry/team/members"
description: "Per-member usage breakdown for the organization."
---

Returns usage statistics broken down by individual team member, including sessions, prompts, cost, and last active timestamp.

**Required scope:** `activity:read`

<Note>Requires organization context via the `X-Organization-Id` header.</Note>

<ParamField query="days" type="integer" default="30">
  Number of days to look back. Range: 1–365.
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  The organization to get member breakdown for.
</ParamField>

<ResponseField name="members" type="TeamMemberStats[]" required>
  Array of per-member usage stats.
</ResponseField>

<ResponseField name="members[].user_id" type="string" required>
  User ID.
</ResponseField>

<ResponseField name="members[].name" type="string">
  Display name.
</ResponseField>

<ResponseField name="members[].email" type="string">
  Email address.
</ResponseField>

<ResponseField name="members[].sessions" type="integer" required>
  Number of sessions created.
</ResponseField>

<ResponseField name="members[].prompts" type="integer" required>
  Number of prompts sent.
</ResponseField>

<ResponseField name="members[].cost_usd" type="number" required>
  Total cost in USD.
</ResponseField>

<ResponseField name="members[].last_active_at" type="string">
  ISO 8601 timestamp of last activity.
</ResponseField>

<ResponseField name="total_members" type="integer" required>
  Total number of active members.
</ResponseField>

<ResponseField name="period_days" type="integer" required>
  Number of days covered.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/sessions/telemetry/team/members?days=30" \

```

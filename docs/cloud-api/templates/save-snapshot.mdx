---
title: "Save Snapshot"
api: "POST /api/org-templates/{template_id}/save-snapshot"
description: "Save current session state as a template snapshot"
---

Saves the current state of a template's fix session as a new E2B template snapshot. This captures the sandbox filesystem so future sessions using this template start from this point. Requires admin or owner role.

**Required scope:** `templates:write`

## Path Parameters

<ParamField path="template_id" type="string" required>
  The template ID (e.g. `tmpl_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  Organization ID.
</ParamField>

## Response

<ResponseField name="status" type="string">
  Operation result (`ok`).
</ResponseField>

<ResponseField name="template_id" type="string">
  The template that was updated.
</ResponseField>

<ResponseField name="e2b_template_id" type="string">
  The new E2B template ID for the snapshot.
</ResponseField>

<ResponseField name="message" type="string">
  Confirmation message.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/org-templates/tmpl_abc123/save-snapshot" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/org-templates/tmpl_abc123/save-snapshot",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)

data = response.json()
print(f"Snapshot saved: {data['e2b_template_id']}")
```

---
title: "Update Template Guardrail"
api: "PATCH /api/org-templates/{template_id}/guardrails/{guardrail_id}"
description: "Edit a template guardrail; omitted fields are left unchanged"
---

Partial update of a template-scoped guardrail. Disabling (`"enabled": false`) stops enforcement while keeping the definition, which is usually better than deleting.

**Required scope:** `guardrails:write`

## Path Parameters

<ParamField path="template_id" type="string" required>
  The template ID.
</ParamField>

<ParamField path="guardrail_id" type="string" required>
  The guardrail ID.
</ParamField>

## Request Body

All fields optional; omitted fields are unchanged.

<ParamField body="type" type="string">
  New type (rarely changed).
</ParamField>

<ParamField body="name" type="string">
  New name.
</ParamField>

<ParamField body="display_name" type="string">
  New display name.
</ParamField>

<ParamField body="description" type="string">
  New description.
</ParamField>

<ParamField body="content" type="object">
  Replacement content object; validated against the type's schema.
</ParamField>

<ParamField body="enabled" type="boolean">
  Enforce or pause the guardrail.
</ParamField>

<ParamField body="position" type="integer">
  New ordering position.
</ParamField>

<RequestExample>
```bash cURL
curl -X PATCH "https://app.runtm.com/api/cloud/org-templates/tmpl_abc123/guardrails/tg_4b2c" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123" \
  -H "Content-Type: application/json" \
  -d '{"enabled": false}'
```

```bash CLI
runtm-api template guardrails update tmpl_abc123 tg_4b2c --disabled
```
</RequestExample>

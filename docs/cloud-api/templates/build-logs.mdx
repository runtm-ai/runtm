---
title: "Build Logs"
api: "GET /api/org-templates/{template_id}/build-logs"
description: "Stream current build logs via Server-Sent Events"
---

Streams the current build logs for a template as Server-Sent Events. If a build is in progress, logs are streamed in real-time. If the build is complete, historical logs are returned immediately.

**Required scope:** `templates:read`

## Path Parameters

<ParamField path="template_id" type="string" required>
  The template ID (e.g. `tmpl_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  Organization ID.
</ParamField>

## Response

Returns a `text/event-stream` with log events. Each line is prefixed with `data: ` and contains a JSON object.

<ResponseField name="type" type="string">
  Log entry type: `log`, `status`, `error`, `complete`.
</ResponseField>

<ResponseField name="message" type="string">
  Log message content.
</ResponseField>

<ResponseField name="timestamp" type="string">
  ISO 8601 timestamp.
</ResponseField>

<RequestExample>
```bash cURL
curl -N "https://app.runtm.com/api/org-templates/tmpl_abc123/build-logs" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/org-templates/tmpl_abc123/build-logs",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
    stream=True,
)

for line in response.iter_lines():
    if line:
        text = line.decode("utf-8")
        if text.startswith("data: "):
            import json
            event = json.loads(text[6:])
            print(f"[{event['type']}] {event['message']}")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/org-templates/tmpl_abc123/build-logs",
  {
    headers: {
      "Authorization": "Bearer runtm_xxx",
      "X-Organization-Id": "org_abc123",
    },
  }
);

const reader = response.body.getReader();
const decoder = new TextDecoder();

while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  const text = decoder.decode(value);
  for (const line of text.split("\n")) {
    if (line.startsWith("data: ")) {
      const event = JSON.parse(line.slice(6));
      console.log(`[${event.type}] ${event.message}`);
    }
  }
}
```

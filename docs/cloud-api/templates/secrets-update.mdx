---
title: "Update Template Secrets"
api: "PUT /api/org-templates/{template_id}/secrets"
description: "Set or update secrets for a template"
---

Bulk upserts secrets for a template. Values are encrypted before storage. Existing secrets with the same key are overwritten. Requires admin or owner role.

**Required scope:** `secrets:write`

## Path Parameters

<ParamField path="template_id" type="string" required>
  The template ID (e.g. `tmpl_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  Organization ID.
</ParamField>

## Body

<ParamField body="secrets" type="object" required>
  Key-value map of secret names to values.
</ParamField>

## Response

<ResponseField name="secrets" type="array">
  Updated list of configured secret key names.
</ResponseField>

<ResponseField name="has_all_required" type="boolean">
  Whether all required secrets are now configured.
</ResponseField>

<RequestExample>
```bash cURL
curl -X PUT "https://app.runtm.com/api/org-templates/tmpl_abc123/secrets" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123" \
  -H "Content-Type: application/json" \
  -d '{
    "secrets": {
      "DATABASE_URL": "postgres://user:pass@host:5432/db",
      "API_SECRET": "sk-secret-value"
    }
  }'
```

```python Python
import requests

response = requests.put(
    "https://app.runtm.com/api/org-templates/tmpl_abc123/secrets",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
        "Content-Type": "application/json",
    },
    json={
        "secrets": {
            "DATABASE_URL": "postgres://user:pass@host:5432/db",
            "API_SECRET": "sk-secret-value",
        }
    },
)

data = response.json()
print(f"Configured: {data['secrets']}")
print(f"All required set: {data['has_all_required']}")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/org-templates/tmpl_abc123/secrets",
  {
    method: "PUT",
    headers: {
      "Authorization": "Bearer runtm_xxx",
      "X-Organization-Id": "org_abc123",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      secrets: {
        DATABASE_URL: "postgres://user:pass@host:5432/db",
        API_SECRET: "sk-secret-value",
      },
    }),
  }
);

const data = await response.json();
console.log(`Configured: ${data.secrets.join(", ")}`);
```

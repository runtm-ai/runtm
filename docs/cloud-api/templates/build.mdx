---
title: "Build Template"
api: "POST /api/org-templates/{template_id}/build"
description: "Trigger a template snapshot build"
---

Triggers a new template build for the organization template. The build runs asynchronously. Use the [Build Logs](/cloud-api/templates/build-logs) endpoint to stream progress. Requires admin or owner role.

**Required scope:** `templates:build`

## Path Parameters

<ParamField path="template_id" type="string" required>
  The template ID (e.g. `tmpl_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  Organization ID.
</ParamField>

## Response

Returns `202 Accepted` when the build is queued.

<ResponseField name="status" type="string">
  Build status (`building`).
</ResponseField>

<ResponseField name="build_id" type="string">
  Unique ID for this build.
</ResponseField>

<ResponseField name="message" type="string">
  Confirmation message.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/cloud/org-templates/tmpl_abc123/build" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/cloud/org-templates/tmpl_abc123/build",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)

data = response.json()
print(f"Build started: {data['build_id']}")
```

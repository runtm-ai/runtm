---
title: "Delete Template Secret"
api: "DELETE /api/org-templates/{template_id}/secrets/{secret_key}"
description: "Delete a single secret from a template"
---

Deletes a specific secret from a template by key name. Requires admin or owner role.

**Required scope:** `secrets:write`

## Path Parameters

<ParamField path="template_id" type="string" required>
  The template ID (e.g. `tmpl_abc123`).
</ParamField>

<ParamField path="secret_key" type="string" required>
  The secret key name to delete (e.g. `DATABASE_URL`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  Organization ID.
</ParamField>

## Response

Returns `200` with the updated secrets list.

<ResponseField name="status" type="string">
  Operation result (`ok`).
</ResponseField>

<ResponseField name="deleted" type="string">
  The key that was deleted.
</ResponseField>

<RequestExample>
```bash cURL
curl -X DELETE "https://app.runtm.com/api/cloud/org-templates/tmpl_abc123/secrets/DATABASE_URL" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

response = requests.delete(
    "https://app.runtm.com/api/cloud/org-templates/tmpl_abc123/secrets/DATABASE_URL",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)

data = response.json()
print(f"Deleted: {data['deleted']}")
```

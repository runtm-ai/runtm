---
title: "Create Template"
api: "POST /api/org-templates"
description: "Create a new organization template"
---

Creates a new organization template from a GitHub repository. Templates define pre-configured sandbox environments that auto-match to repositories based on repository patterns. Requires admin or owner role.

**Required scope:** `templates:write`

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  Organization ID.
</ParamField>

## Body

<ParamField body="name" type="string">
  Optional template slug name. If omitted, Runtime derives one from the repository and branch. Must be unique within the organization.
</ParamField>

<ParamField body="display_name" type="string" required>
  Human-readable template name.
</ParamField>

<ParamField body="description" type="string">
  Template description.
</ParamField>

<ParamField body="github_repo" type="string" required>
  GitHub repository in `owner/repo` form to use as the template source.
</ParamField>

<ParamField body="github_branch" type="string" default="main">
  Branch to use from the source repository.
</ParamField>

<ParamField body="agents" type="array" default='["claude-code"]'>
  Coding agents this template should support. Use an array, even for one agent. Valid values: `claude-code`, `codex`, `github-copilot`, `opencode`.
</ParamField>

<ParamField body="tier" type="string" default="basic">
  Resource tier for template sessions. Valid values: `basic`, `standard`, `max`.
</ParamField>

<ParamField body="build_spec" type="object">
  Optional seed build spec. Runtime may rewrite this during the template build.
</ParamField>

<ParamField body="github_repos" type="array">
  Optional multi-repo configuration. Each entry includes `full_name`, `branch`, optional `workdir`, and optional `is_primary`.
</ParamField>

`agent` is not a create-template field. To create a Codex template, send `"agents": ["codex"]`.

## Response

Returns `201` with the created template resource.

<ResponseField name="id" type="string">
  Template ID.
</ResponseField>

<ResponseField name="name" type="string">
  Template slug name.
</ResponseField>

<ResponseField name="display_name" type="string">
  Human-readable name.
</ResponseField>

<ResponseField name="github_repo" type="string">
  GitHub repository used as the template source.
</ResponseField>

<ResponseField name="build_status" type="string">
  Initial build status.
</ResponseField>

<ResponseField name="framework" type="string">
  Detected framework, or `null` when it has not been detected yet.
</ResponseField>

<ResponseField name="agents" type="array">
  Agents configured for the template.
</ResponseField>

```bash cURL
curl -X POST "https://app.runtm.com/api/cloud/org-templates" \
  -H "Authorization: Bearer runtm_xxx" \

```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/cloud/org-templates",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
        "Content-Type": "application/json",
    },
    json={
        "name": "nextjs-starter",
        "display_name": "Next.js Starter",
        "description": "Pre-configured Next.js with Tailwind CSS",
        "github_repo": "owner/nextjs-starter",
        "github_branch": "main",
        "tier": "basic",
        "agents": ["codex"],
    },
)

data = response.json()
print(f"Created template: {data['id']}")
```

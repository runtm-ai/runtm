---
title: "Create Template"
api: "POST /api/org-templates"
description: "Create a new organization template"
---

Creates a new organization template. Templates define pre-configured sandbox environments that auto-match to repositories based on glob patterns. Requires admin or owner role.

**Required scope:** `templates:write`

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  Organization ID.
</ParamField>

## Body

<ParamField body="name" type="string" required>
  Template slug name (must be unique within the org).
</ParamField>

<ParamField body="display_name" type="string" required>
  Human-readable template name.
</ParamField>

<ParamField body="description" type="string">
  Template description.
</ParamField>

<ParamField body="repo_url" type="string">
  GitHub repository URL to use as the template source.
</ParamField>

<ParamField body="branch" type="string">
  Branch to use from the source repository.
</ParamField>

<ParamField body="agent" type="string" default="claude-code">
  Default agent for sessions using this template.
</ParamField>

<ParamField body="config" type="object">
  Template configuration including tier, repo patterns, and build spec.
</ParamField>

## Response

Returns `201` with the created template resource.

<ResponseField name="id" type="string">
  Template ID.
</ResponseField>

<ResponseField name="name" type="string">
  Template slug name.
</ResponseField>

<ResponseField name="display_name" type="string">
  Human-readable name.
</ResponseField>

<ResponseField name="build_status" type="string">
  Initial build status.
</ResponseField>

```bash cURL
    "agent": "claude-code",

```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/cloud/org-templates",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
        "Content-Type": "application/json",
    },
    json={
        "name": "nextjs-starter",
        "display_name": "Next.js Starter",
        "description": "Pre-configured Next.js with Tailwind CSS",
        "repo_url": "https://github.com/owner/nextjs-starter",
        "branch": "main",
        "agent": "claude-code",
        "config": {
            "tier": "starter",
            "repo_patterns": ["owner/nextjs-*"],
        },
    },
)

data = response.json()
print(f"Created template: {data['id']}")
```

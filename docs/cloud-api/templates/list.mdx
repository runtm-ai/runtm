---
title: "List Templates"
api: "GET /api/org-templates"
description: "List organization templates with pagination"
---

Returns a paginated list of organization templates. Templates define pre-configured sandbox environments with custom E2B images, repo patterns, and secrets.

**Required scope:** `templates:read`

## Query Parameters

<ParamField query="page_size" type="integer" default="20">
  Number of results per page (1–100).
</ParamField>

<ParamField query="page_token" type="string">
  Opaque cursor from a previous response for pagination.
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  Organization ID. Templates are org-scoped.
</ParamField>

## Response

<ResponseField name="templates" type="array">
  Array of template resources with metadata, build status, and configuration.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/org-templates?page_size=10" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/org-templates",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
    params={"page_size": 10},
)

data = response.json()
for t in data["templates"]:
    print(f"{t['display_name']} ({t['build_status']})")
```

```javascript JavaScript

    },

```

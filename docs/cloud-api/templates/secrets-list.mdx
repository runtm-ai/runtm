---
title: "List Template Secrets"
api: "GET /api/org-templates/{template_id}/secrets"
description: "List secret names configured for a template"
---

Returns the list of secret keys configured for a template. Values are never returned - only names and whether they are set.

**Required scope:** `secrets:read`

## Path Parameters

<ParamField path="template_id" type="string" required>
  The template ID (e.g. `tmpl_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  Organization ID.
</ParamField>

## Response

<ResponseField name="secrets" type="array">
  Array of secret key names configured for the template.
</ResponseField>

<ResponseField name="required_secrets" type="array">
  Secret keys required by the template.
</ResponseField>

<ResponseField name="has_all_required" type="boolean">
  Whether all required secrets are configured.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/org-templates/tmpl_abc123/secrets" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/org-templates/tmpl_abc123/secrets",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)

data = response.json()
print(f"Configured: {data['secrets']}")
print(f"Required: {data['required_secrets']}")
print(f"All set: {data['has_all_required']}")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/org-templates/tmpl_abc123/secrets",
  {

console.log(`All required set: ${data.has_all_required}`);
```

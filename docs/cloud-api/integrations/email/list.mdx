---
title: "List Email Integrations"
api: "GET /api/v1/email/integrations"
description: "List the organization's email inboxes"
---

Lists the org's email trigger inboxes. Each inbox launches or follows up a session when mail arrives at its address. There is no get-by-id route; filter this list client-side.

**Required scope:** `integrations:read`

## Headers

<ParamField header="X-Organization-Id" type="string" required>
  Organization ID.
</ParamField>

## Response

<ResponseField name="available" type="boolean">
  Whether the email provider is configured.
</ResponseField>

<ResponseField name="integrations" type="array">
  Integration objects: `{id, name, inbox_email, inbox_id, enabled, default_template, default_github_repo, default_agent, rate_limit_per_hour, config, created_at}`.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/cloud/v1/email/integrations" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```bash CLI
runtm-api agents list --type email
```
</RequestExample>

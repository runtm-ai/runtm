---
title: "Delete Agent Directive"
api: "DELETE /agent-directives/{directive_id}"
description: "Delete a directive and all its versions"
---

Deletes the directive and all of its versions. Sessions can still complete in-flight overlay applies, but new sessions will no longer pick up the directive.

<Info>Required scope: `context:write`</Info>

<Note>
Agent directives are **organization-scoped**. The request must include `X-Organization-Id` (or use an org-scoped API key).
</Note>

## Path Parameters

<ParamField path="directive_id" type="string" required>
  Directive id.
</ParamField>

## Headers

<ParamField header="X-Organization-Id" type="string" required>
  The organization context.
</ParamField>

## Response

`204 No Content` on success - the response body is empty.

<RequestExample>
```bash cURL
curl -X DELETE "https://app.runtm.com/api/agent-directives/dir_aaa" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_456"
```

```python Python
import requests

response = requests.delete(
    "https://app.runtm.com/api/agent-directives/dir_aaa",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_456",
    },
)

print(response.status_code)
```

```javascript JavaScript
const response = await fetch(
```

</RequestExample>

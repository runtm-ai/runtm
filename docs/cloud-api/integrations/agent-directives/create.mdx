---
title: "Create Agent Directive"
api: "POST /agent-directives/"
description: "Create a new agent directive (skill, MCP server, doc, rule, or hook)"
---

Creates a new agent directive at version 1. The new directive is **unpublished** - it does not affect any sessions until you call [Publish Directive](/cloud-api/integrations/agent-directives/publish).

The valid shape of `content` depends on `type`:

| `type`              | `content` shape                                                          |
| ------------------- | ------------------------------------------------------------------------ |
| `skill_v0`          | `entry_md`, `files[]`, optional `runtime_env`, `frontmatter`, `requires` |
| `mcp_server_v0`     | `transport` + transport-specific fields (`command`/`args`/`env` for stdio; `url`/`headers` for http/sse) |
| `doc_v0`            | `url` (single reference URL)                                             |
| `network_rule_v0`   | `kind` (`host`/`cidr`), `value`, optional `purpose`                      |
| `allowlist_rule_v0` | `kind` (`allow`/`ask`/`deny`), `pattern`, optional `purpose`             |
| `hook_v0`           | `event`, `script`, optional `matcher`, `timeout`, `async`                |

Hook directives have a stricter slug rule on `name`: it must match `^[a-z0-9][a-z0-9-]{0,63}$`.

<Info>Required scope: `context:write`</Info>

<Note>
Agent directives are **organization-scoped**. The request must include `X-Organization-Id` (or use an org-scoped API key).
</Note>

## Body Parameters

<ParamField body="type" type="string" default="skill_v0">
  One of `skill_v0`, `mcp_server_v0`, `doc_v0`, `network_rule_v0`, `allowlist_rule_v0`, `hook_v0`.
</ParamField>

<ParamField body="name" type="string" required>
  Directive name. 1-128 characters (stricter slug for `hook_v0`).
</ParamField>

<ParamField body="display_name" type="string">
  Optional human-readable display name.
</ParamField>

<ParamField body="description" type="string">
  Optional description.
</ParamField>

<ParamField body="content" type="object" required>
  The directive's payload. Shape depends on `type` (see table above).
</ParamField>

## Headers

<ParamField header="X-Organization-Id" type="string" required>
  The organization context.
</ParamField>

## Response

<ResponseField name="directive" type="object">
  The newly created directive (version 1, unpublished).
</ResponseField>

```bash cURL
curl -X POST "https://app.runtm.com/api/agent-directives/" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_456" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "skill_v0",
    "name": "deploy-checks",
    "display_name": "Pre-deploy checks",
    "content": {
      "entry_md": "SKILL.md",
      "files": [
        {"path": "SKILL.md", "mode": "text", "inline": "# Deploy checks\n\nRun lint, typecheck, tests."}
      ]
    }
  }'
```

        "display_name": "Pre-deploy checks",

                    "path": "SKILL.md",

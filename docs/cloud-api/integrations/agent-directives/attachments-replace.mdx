---
title: "Replace Directive Attachments"
api: "PUT /agent-directives/{directive_id}/attachments"
description: "Replace the full list of repositories a directive is attached to"
---

Replaces the full set of repository attachments for a directive. The previous attachments are removed and the supplied list takes effect immediately for new sessions.

Two mutually-exclusive modes are supported:

* `repo_full_names: ["owner/repo", ...]` - attach to a specific list of repos. `applies_to_all` must be `false`.
* `applies_to_all: true` - attach to every repository in the organization. `repo_full_names` is ignored.

<Info>Required scope: `context:write`</Info>

<Note>
Agent directives are **organization-scoped**. The request must include `X-Organization-Id` (or use an org-scoped API key).
</Note>

## Path Parameters

<ParamField path="directive_id" type="string" required>
  Directive id.
</ParamField>

## Body Parameters

<ParamField body="repo_full_names" type="array">
  List of `owner/name` strings to attach the directive to.
</ParamField>

<ParamField body="applies_to_all" type="boolean" default="false">
  If true, attach to every repository in the organization instead of a specific list.
</ParamField>

## Headers

<ParamField header="X-Organization-Id" type="string" required>
  The organization context.
</ParamField>

## Response

<ResponseField name="attachments" type="array">
  The new attachment list. Same shape as [List Attachments](/cloud-api/integrations/agent-directives/attachments-list).
</ResponseField>

<RequestExample>
```bash cURL
curl -X PUT "https://app.runtm.com/api/agent-directives/dir_aaa/attachments" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_456" \
  -H "Content-Type: application/json" \
  -d '{
    "repo_full_names": ["acme-corp/backend", "acme-corp/frontend"],
    "applies_to_all": false
  }'
```

```python Python
import requests

response = requests.put(
    "https://app.runtm.com/api/agent-directives/dir_aaa/attachments",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_456",
    },
    json={
        "repo_full_names": ["acme-corp/backend", "acme-corp/frontend"],
        "applies_to_all": False,
    },
)

print(response.json())
```

```javascript JavaScript
const response = await fetch(

  }

```

---
title: "Publish Directive Version"
api: "POST /agent-directives/{directive_id}:publish"
description: "Publish the current draft version, atomically switching traffic over"
---

Publishes the current draft version of a directive. New sessions will receive the published version through the runtime overlay. Existing sessions continue to use whatever version they were bootstrapped with.

<Info>Required scope: `context:write`</Info>

<Note>
Agent directives are **organization-scoped**. The request must include `X-Organization-Id` (or use an org-scoped API key).
</Note>

## Path Parameters

<ParamField path="directive_id" type="string" required>
  Directive id.
</ParamField>

## Headers

<ParamField header="X-Organization-Id" type="string" required>
  The organization context.
</ParamField>

## Response

<ResponseField name="directive" type="object">
  The published directive.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/agent-directives/dir_aaa:publish" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_456"
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/agent-directives/dir_aaa:publish",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_456",
    },
)

print(response.json())
```

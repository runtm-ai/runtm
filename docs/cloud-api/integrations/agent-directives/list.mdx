---
title: "List Agent Directives"
api: "GET /agent-directives/"
description: "Paginated list of agent directives in the organization"
---

Returns a paginated list of agent directives - skills, MCP server configurations, reference docs, network rules, allowlist rules, and hooks - that ship into agent sandboxes via the runtime overlay.

<Info>Required scope: `context:read`</Info>

<Note>
Agent directives are **organization-scoped**. The request must include `X-Organization-Id` (or use an org-scoped API key).
</Note>

## Query Parameters

<ParamField query="repo_full_name" type="string">
  Filter to directives attached to this repo (`owner/name`).
</ParamField>

<ParamField query="type_family" type="string" default="skill">
  Directive family (e.g. `skill`, `mcp_server`, `doc`, `network_rule`, `allowlist_rule`, `hook`).
</ParamField>

<ParamField query="is_published" type="boolean">
  Filter by published state.
</ParamField>

<ParamField query="page_size" type="integer" default="20">
  Page size. Range: 1-100.
</ParamField>

<ParamField query="page_token" type="string">
  Opaque pagination token from a previous response's `next_page_token`.
</ParamField>

<ParamField query="include_content" type="boolean" default="false">
  When `true`, includes the full directive `content` payload. Otherwise content is omitted to keep list responses small.
</ParamField>

## Headers

<ParamField header="X-Organization-Id" type="string" required>
  The organization context.
</ParamField>

## Response

<ResponseField name="directives" type="array">
  Directive records. Same canonical shape as [Get Directive](/cloud-api/integrations/agent-directives/get).
</ResponseField>

<ResponseField name="next_page_token" type="string">
  Token to pass as `page_token` for the next page. `null` when no more pages.
</ResponseField>

<ResponseField name="total_size" type="integer">
  Total directives matching the filter.
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://app.runtm.com/api/agent-directives/?type_family=skill&is_published=true" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_456"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/agent-directives/",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_456",
    },
    params={"type_family": "skill", "is_published": "true"},
)

for directive in response.json()["directives"]:
    print(f"{directive['name']} v{directive['version']}")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/agent-directives/?type_family=skill&is_published=true",
  {
    headers: {
      "Authorization": "Bearer runtm_xxx",
      "X-Organization-Id": "org_456",
    },
  }

const data = await response.json();
for (const d of data.directives) {
  console.log(`${d.name} v${d.version}`);
}
```

---
title: "Get Agent Directive"
api: "GET /agent-directives/{directive_id}"
description: "Get a single agent directive, optionally with full content"
---

Returns a single agent directive. By default the `content` field is omitted to keep responses cheap. Pass `include_content=true` to receive the full content payload - for `object_ref` directives, file references will include short-lived presigned download URLs.

<Info>Required scope: `context:read`</Info>

<Note>
Agent directives are **organization-scoped**. The request must include `X-Organization-Id` (or use an org-scoped API key).
</Note>

## Path Parameters

<ParamField path="directive_id" type="string" required>
  Directive id.
</ParamField>

## Query Parameters

<ParamField query="include_content" type="boolean" default="false">
  When `true`, include the full directive `content` payload.
</ParamField>

## Headers

<ParamField header="X-Organization-Id" type="string" required>
  The organization context.
</ParamField>

## Response

<ResponseField name="directive" type="object">
  <Expandable title="DirectiveResource">
    <ResponseField name="id" type="string">
      Stable directive id.
    </ResponseField>
    <ResponseField name="type" type="string">
      Directive type (e.g. `skill_v0`, `hook_v0`).
    </ResponseField>
    <ResponseField name="name" type="string">
      Directive name.
    </ResponseField>
    <ResponseField name="display_name" type="string">
      Optional human-readable display name.
    </ResponseField>
    <ResponseField name="description" type="string">
      Optional description.
    </ResponseField>
    <ResponseField name="version" type="integer">
      Directive version. Each publish bumps this.
    </ResponseField>
    <ResponseField name="is_published" type="boolean">
      True if the version is currently published.
    </ResponseField>
    <ResponseField name="organization_id" type="string">
      Owning organization.
    </ResponseField>
    <ResponseField name="owner_user_id" type="string">
      User who created this version.
    </ResponseField>
    <ResponseField name="content_kind" type="string">
      `inline` or `object_ref`. `object_ref` directives store large content in object storage; their files have `ref` (and optionally `url` when `include_content=true`).
    </ResponseField>
    <ResponseField name="content_hash" type="string">
      Content-addressable digest (`sha256:<hex>`).
    </ResponseField>
    <ResponseField name="size_bytes" type="integer">
      Total content size in bytes.
    </ResponseField>
    <ResponseField name="source" type="object">
      Origin of the directive's content (inline / GitHub repo / GitHub URL / external URL).
    </ResponseField>
    <ResponseField name="attachments" type="object">
      Summary of which repos this directive applies to.
    </ResponseField>
    <ResponseField name="content" type="object">
      The directive payload. Only populated when `include_content=true`.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      ISO 8601 creation timestamp.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      ISO 8601 last-update timestamp, or `null`.
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://app.runtm.com/api/agent-directives/dir_aaa?include_content=true" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_456"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/agent-directives/dir_aaa",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_456",
    },
    params={"include_content": "true"},
)

print(response.json())
```

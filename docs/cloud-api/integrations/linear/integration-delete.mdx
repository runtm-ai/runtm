---
title: "Delete Integration"
api: "DELETE /api/v1/linear/integration"
description: "Disconnect the Linear integration for the organization."
---

Disconnects the Linear integration by deleting the webhook, revoking the token, and removing the integration record. Requires org admin role.

**Required scope:** `integrations:write`

<Note>Requires organization context via the `X-Organization-Id` header.</Note>

<ParamField header="X-Organization-Id" type="string" required>
  The organization to disconnect.
</ParamField>

<ResponseField name="success" type="boolean" required>
  Whether the disconnection succeeded.
</ResponseField>

<RequestExample>
```bash cURL
curl -X DELETE "https://app.runtm.com/api/v1/linear/integration" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

resp = requests.delete(
    "https://app.runtm.com/api/v1/linear/integration",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)
print(resp.json())
```

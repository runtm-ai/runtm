---
title: "Get Integration"
api: "GET /api/v1/linear/integration"
description: "Get the current Linear integration status and configuration."
---

Returns the Linear integration status for the active organization, including workspace info, webhook status, and configuration settings.

**Required scope:** `integrations:read`

<Note>Requires organization context via the `X-Organization-Id` header.</Note>

<ParamField header="X-Organization-Id" type="string" required>
  The organization to check.
</ParamField>

<ResponseField name="connected" type="boolean" required>
  Whether a Linear integration exists.
</ResponseField>

<ResponseField name="workspace_name" type="string">
  Linear workspace name.
</ResponseField>

<ResponseField name="actor_name" type="string">
  Name of the authorized actor.
</ResponseField>

<ResponseField name="service_user_id" type="string">
  Runtime user ID used as the service account.
</ResponseField>

<ResponseField name="default_github_repo" type="string">
  Default GitHub repo for agent sessions.
</ResponseField>

<ResponseField name="default_template" type="string">
  Default sandbox template.
</ResponseField>

<ResponseField name="default_agent" type="string" required>
  Default coding agent (e.g. `"claude-code"`).
</ResponseField>

<ResponseField name="rate_limit_per_hour" type="integer" required>
  Maximum agent launches per hour.
</ResponseField>

<ResponseField name="enabled" type="boolean" required>
  Whether the integration is enabled.
</ResponseField>

<ResponseField name="webhook_active" type="boolean" required>
  Whether the webhook is registered.
</ResponseField>

<ResponseField name="bot_linear_user_id" type="string">
  The app's user ID in the Linear workspace.
</ResponseField>

<ResponseField name="project_repo_map" type="object">
  Mapping of Linear project IDs to GitHub repos.
</ResponseField>

```bash cURL
curl "https://app.runtm.com/api/v1/linear/integration" \
```

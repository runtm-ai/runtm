---
title: "Delete User Connection"
api: "DELETE /api/v1/linear/user-connection"
description: "Remove the current user's personal Linear identity link."
---

Disconnects the current user's Linear identity link. Revokes the stored access token and removes the connection record. This does not affect the org-level Linear integration.

**Required scope:** `integrations:write`

<Note>Requires organization context via the `X-Organization-Id` header.</Note>

<ParamField header="X-Organization-Id" type="string" required>
  The organization context.
</ParamField>

<ResponseField name="success" type="boolean" required>
  Whether the disconnection succeeded.
</ResponseField>

<RequestExample>
```bash cURL
curl -X DELETE "https://app.runtm.com/api/v1/linear/user-connection" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

resp = requests.delete(
    "https://app.runtm.com/api/v1/linear/user-connection",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)
print(resp.json())
```

---
title: "OAuth Install URL"
api: "GET /api/v1/linear/oauth/install-url"
description: "Get the OAuth URL to install the Linear integration."
---

Returns the Linear OAuth authorization URL for the managed Runtime app. After the user authorizes on Linear, they are redirected back to complete the integration setup.

Requires org admin role.

**Required scope:** `integrations:write`

<Note>Requires organization context via the `X-Organization-Id` header.</Note>

<ParamField header="X-Organization-Id" type="string" required>
  The organization to install the integration for.
</ParamField>

<ParamField query="dev_proxy_url" type="string">
  Optional. Dev server URL for OAuth proxy redirect during local development.
</ParamField>

<ResponseField name="url" type="string" required>
  Linear OAuth authorization URL. Redirect the user here.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/v1/linear/oauth/install-url" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

resp = requests.get(
    "https://app.runtm.com/api/v1/linear/oauth/install-url",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)
data = resp.json()
print(f"Redirect user to: {data['url']}")
```

```javascript JavaScript
const resp = await fetch(
  "https://app.runtm.com/api/v1/linear/oauth/install-url",
  {
    headers: {

```
</RequestExample>

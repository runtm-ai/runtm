---
title: "Get Integration"
api: "GET /api/v1/slack/integration"
description: "Get the Slack integration configuration and status."
---

Returns the current Slack integration status for the active organization, including connection type, team info, service account health, and configuration.

**Required scope:** `integrations:read`

<Note>Requires organization context via the `X-Organization-Id` header.</Note>

<ParamField header="X-Organization-Id" type="string" required>
  The organization to check.
</ParamField>

<ResponseField name="connected" type="boolean" required>
  Whether a Slack integration exists.
</ResponseField>

<ResponseField name="connection_type" type="string" required>
  `"oauth"` for managed app or `"manual"` for self-hosted.
</ResponseField>

<ResponseField name="managed_app_available" type="boolean" required>
  Whether the managed OAuth app is configured.
</ResponseField>

<ResponseField name="team_name" type="string">
  Slack workspace name.
</ResponseField>

<ResponseField name="bot_user_id" type="string">
  Slack bot user ID.
</ResponseField>

<ResponseField name="service_user_id" type="string">
  Runtime user ID used as the service account.
</ResponseField>

<ResponseField name="service_user_name" type="string">
  Display name of the service account user.
</ResponseField>

<ResponseField name="default_template" type="string">
  Default sandbox template.
</ResponseField>

<ResponseField name="default_github_repo" type="string">
  Default GitHub repo for agent sessions.
</ResponseField>

<ResponseField name="default_agent" type="string" required>
  Default coding agent.
</ResponseField>

<ResponseField name="rate_limit_per_hour" type="integer" required>
  Maximum agent launches per hour.
</ResponseField>

<ResponseField name="enabled" type="boolean" required>
  Whether the integration is enabled.
</ResponseField>

<ResponseField name="interactivity_confirmed" type="boolean" required>
  Whether Slack interactivity has been verified.
</ResponseField>

<ResponseField name="channel_repo_map" type="object">
  Channel ID to GitHub repo mapping.
</ResponseField>

<ResponseField name="service_account_health" type="object" required>
  Health status with `healthy` boolean and `issues` array.
</ResponseField>

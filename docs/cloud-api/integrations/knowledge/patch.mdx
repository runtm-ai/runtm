---
title: "Update Knowledge Integration"
api: "PATCH /knowledge/integrations/{integration_id}"
description: "Update non-credential fields on a knowledge integration"
---

Partially updates a knowledge integration. Only non-credential fields are updatable here - to rotate the actual credential, use [Rotate Credentials](/cloud-api/integrations/knowledge/rotate). Omitted fields are left unchanged.

<Info>Required scope: `integrations:write`</Info>

<Note>
This endpoint is **organization-only**. The request must include `X-Organization-Id` (or use an org-scoped API key).
</Note>

## Path Parameters

<ParamField path="integration_id" type="string" required>
  Knowledge integration id.
</ParamField>

## Body Parameters

<ParamField body="display_name" type="string">
  New display name (max 200 chars). Pass an empty string to clear.
</ParamField>

<ParamField body="provider_metadata" type="object">
  Replace the integration's `provider_metadata` map.
</ParamField>

<ParamField body="default_mode" type="string">
  Default per-tool permission (`auto`, `allow`, `ask`).
</ParamField>

<ParamField body="tool_permissions" type="object">
  Per-tool permission overrides, keyed by tool id. Each value must be `auto`, `allow`, or `ask`.
</ParamField>

## Headers

<ParamField header="X-Organization-Id" type="string" required>
  The organization context.
</ParamField>

## Response

<ResponseField name="integration" type="object">
  The updated integration. Same shape as [Get Integration](/cloud-api/integrations/knowledge/get).
</ResponseField>

<RequestExample>
```bash cURL
curl -X PATCH "https://app.runtm.com/api/knowledge/integrations/kint_aaa" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_456" \
  -H "Content-Type: application/json" \
  -d '{"default_mode": "auto", "tool_permissions": {"query": "ask"}}'
```

```python Python
import requests

response = requests.patch(
    "https://app.runtm.com/api/knowledge/integrations/kint_aaa",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_456",
    },
    json={"default_mode": "auto", "tool_permissions": {"query": "ask"}},
)

print(response.json())
```

---
title: "Get Knowledge Catalog"
api: "GET /knowledge/catalog"
description: "List every available knowledge provider and its supported auth methods + tools"
---

Returns the static catalog of every knowledge provider Runtime can integrate with - what each provider does, which auth methods it supports (OAuth or static credentials), and the tools each one exposes to agents. The catalog is resolved entirely from code; this endpoint does not query the database.

Use this to drive the provider picker in your UI: each catalog entry has the metadata needed to render a card and choose how to connect.

<Info>Required scope: `integrations:read`</Info>

## Response

<ResponseField name="providers" type="array">
  Catalog entries, one per provider.
  <Expandable title="CatalogProviderResource">
    <ResponseField name="id" type="string">
      Provider id (e.g. `bigquery`, `notion`).
    </ResponseField>
    <ResponseField name="display_name" type="string">
      Human-readable provider name.
    </ResponseField>
    <ResponseField name="tagline" type="string">
      One-line tagline for use in cards.
    </ResponseField>
    <ResponseField name="description" type="string">
      Longer description explaining the provider.
    </ResponseField>
    <ResponseField name="category" type="string">
      Grouping category (e.g. `data-warehouse`, `docs`).
    </ResponseField>
    <ResponseField name="icon" type="string">
      Icon identifier (e.g. an icon name or path the UI knows how to render).
    </ResponseField>
    <ResponseField name="accent_color" type="string">
      Brand accent color (CSS hex).
    </ResponseField>
    <ResponseField name="docs_url" type="string">
      Optional link to the provider's external documentation.
    </ResponseField>
    <ResponseField name="auth_methods" type="array">
      Auth methods the provider supports.
      <Expandable title="CatalogAuthMethodResource">
        <ResponseField name="id" type="string">
          Auth method id.
        </ResponseField>
        <ResponseField name="display_name" type="string">
          Human-readable method name.
        </ResponseField>
        <ResponseField name="description" type="string">
          Longer description.
        </ResponseField>
        <ResponseField name="auth_kind" type="string">
          `oauth` or `static`.
        </ResponseField>
        <ResponseField name="oauth_scopes" type="array">
          OAuth scopes requested (only for `oauth` methods).
        </ResponseField>
        <ResponseField name="credential_schema" type="object">
          JSON-schema-style description of credential fields (only for `static` methods).
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="tools" type="array">
      Tools the provider exposes to agents.
      <Expandable title="CatalogToolResource">
        <ResponseField name="id" type="string">
          Tool id (used in `tool_permissions` on integrations).
        </ResponseField>
        <ResponseField name="name" type="string">
          Display name.
        </ResponseField>
        <ResponseField name="description" type="string">
          What the tool does.
        </ResponseField>
        <ResponseField name="kind" type="string">
          `read` or `write`.
        </ResponseField>
        <ResponseField name="default_permission" type="string">
          Default per-tool permission (`auto`, `allow`, or `ask`).
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://app.runtm.com/api/knowledge/catalog" \
  -H "Authorization: Bearer runtm_xxx"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/knowledge/catalog",
    headers={"Authorization": "Bearer runtm_xxx"},
)

for provider in response.json()["providers"]:
    methods = [m["id"] for m in provider["auth_methods"]]
    print(f"{provider['id']}: {methods}")
```

```javascript JavaScript
const response = await fetch("https://app.runtm.com/api/knowledge/catalog", {
  headers: { "Authorization": "Bearer runtm_xxx" },
});

const data = await response.json();
for (const p of data.providers) {
  const methods = p.auth_methods.map(m => m.id);
  console.log(`${p.id}: ${methods.join(", ")}`);
}
```
</RequestExample>

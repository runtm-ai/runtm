---
title: "Rotate Knowledge Credentials"
api: "POST /knowledge/integrations/{integration_id}:rotate"
description: "Replace stored credentials, optionally switching to a different static auth method"
---

Replaces the stored credentials on a knowledge integration, and optionally switches to a different `auth_method` (provided the new method is also `static`). For OAuth methods, use the [OAuth install flow](/cloud-api/integrations/knowledge/oauth-install) to reconnect.

The new credentials must match the schema declared by the chosen `auth_method` in the [catalog](/cloud-api/integrations/knowledge/catalog). Credentials are encrypted at rest and never echoed back.

<Info>Required scope: `integrations:write`</Info>

<Note>
This endpoint is **organization-only**. The request must include `X-Organization-Id` (or use an org-scoped API key).
</Note>

## Path Parameters

<ParamField path="integration_id" type="string" required>
  Knowledge integration id.
</ParamField>

## Body Parameters

<ParamField body="auth_method" type="string" required>
  Auth method id. Must be a `static` method on the same provider.
</ParamField>

<ParamField body="credentials" type="object" required>
  New credential payload matching the auth method's schema.
</ParamField>

<ParamField body="provider_metadata" type="object">
  Optional update to `provider_metadata`. Omit to leave unchanged.
</ParamField>

## Headers

<ParamField header="X-Organization-Id" type="string" required>
  The organization context.
</ParamField>

## Response

<ResponseField name="integration" type="object">
  The rotated integration. Same shape as [Get Integration](/cloud-api/integrations/knowledge/get).
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/knowledge/integrations/kint_aaa:rotate" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_456" \
  -H "Content-Type: application/json" \
  -d '{
    "auth_method": "api-key",
    "credentials": { "api_key": "secret_new" }
  }'
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/knowledge/integrations/kint_aaa:rotate",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_456",
    },
    json={
        "auth_method": "api-key",
        "credentials": {"api_key": "secret_new"},
    },
)

print(response.json())
```


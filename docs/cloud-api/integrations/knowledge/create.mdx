---
title: "Create Knowledge Integration"
api: "POST /knowledge/integrations"
description: "Create a knowledge integration with static credentials"
---

Creates a knowledge integration using a **static** credential method (e.g. API key, service-account JSON). For OAuth methods, use the [OAuth install flow](/cloud-api/integrations/knowledge/oauth-install) instead.

The `credentials` map must match the schema declared by the chosen `auth_method` in the [catalog](/cloud-api/integrations/knowledge/catalog). Credentials are encrypted at rest and never returned in subsequent reads - only `has_credentials: true` is exposed.

<Info>Required scope: `integrations:write`</Info>

<Note>
This endpoint is **organization-only**. The request must include `X-Organization-Id` (or use an org-scoped API key).
</Note>

## Body Parameters

<ParamField body="provider" type="string" required>
  Provider id from the catalog (e.g. `bigquery`).
</ParamField>

<ParamField body="auth_method" type="string" required>
  Auth method id supported by the provider, with `auth_kind: "static"`.
</ParamField>

<ParamField body="scope" type="string" default="org">
  `org` for an org-shared connection, or `personal` for a user-only override.
</ParamField>

<ParamField body="display_name" type="string">
  Optional display name (max 200 chars).
</ParamField>

<ParamField body="credentials" type="object" required>
  Credential payload matching the auth method's `credential_schema`. Encrypted at rest, never echoed back.
</ParamField>

<ParamField body="provider_metadata" type="object">
  Free-form metadata stored alongside the connection (e.g. project ids, region).
</ParamField>

<ParamField body="default_mode" type="string">
  Default per-tool permission for tools without an explicit override (`auto`, `allow`, `ask`).
</ParamField>

## Headers

<ParamField header="X-Organization-Id" type="string" required>
  The organization context.
</ParamField>

## Response

<ResponseField name="integration" type="object">
  The newly created integration. See [Get Integration](/cloud-api/integrations/knowledge/get) for the full canonical shape.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/knowledge/integrations" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_456" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "notion",
    "auth_method": "api-key",
    "scope": "org",
    "display_name": "Acme Notion",
    "credentials": { "api_key": "secret_xxx" },
    "provider_metadata": { "workspace": "acme" }
  }'
```

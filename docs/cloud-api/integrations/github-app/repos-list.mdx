---
title: "List Repos"
api: "GET /api/github-app/repos"
description: "All repos accessible via installed GitHub Apps, fetched in parallel."
---

Returns repositories from all accessible GitHub App installations in a single call. Repos are grouped by installation and fetched in parallel for fast loading.

**Required scope:** `integrations:read`

<ParamField query="per_page" type="integer" default="100">
  Number of repos per installation. Range: 1–100.
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Optional. When set, includes repos from org-shared installations.
</ParamField>

<ResponseField name="installations" type="InstallationRepos[]" required>
  List of installations with their repos.
</ResponseField>

<ResponseField name="installations[].installation" type="InstallationInfo" required>
  Installation metadata (see [List Installations](/cloud-api/integrations/github-app/installations-list)).
</ResponseField>

<ResponseField name="installations[].repos" type="RepoInfo[]" required>
  Repositories accessible to this installation.
</ResponseField>

<ResponseField name="installations[].repos[].id" type="integer" required>
  GitHub repository ID.
</ResponseField>

<ResponseField name="installations[].repos[].full_name" type="string" required>
  Full repository name (`owner/repo`).
</ResponseField>

<ResponseField name="installations[].repos[].private" type="boolean" required>
  Whether the repo is private.
</ResponseField>

<ResponseField name="installations[].repos[].default_branch" type="string" required>
  Default branch name.
</ResponseField>

<ResponseField name="installations[].repos[].language" type="string">
  Primary language.
</ResponseField>

<ResponseField name="installations[].total_count" type="integer" required>
  Total number of repos in this installation.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/github-app/repos?per_page=50" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

resp = requests.get(
    "https://app.runtm.com/api/github-app/repos",
    params={"per_page": 50},
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)
print(resp.json())
```

```javascript JavaScript
const resp = await fetch(

    },
  }
```

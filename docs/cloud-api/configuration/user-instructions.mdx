---
title: "User Instructions"
api: "GET/PUT /api/user/instructions"
description: "Read and write the caller's custom Claude instructions for the current personal or organization context."
---

User custom instructions are appended to the `CLAUDE.md` of every session
the caller creates. They sit between **org instructions** and **session-level
instructions** in the resolution order:

```
System  →  Org Instructions  →  User Instructions  →  Session Instructions
```

User instructions are scoped per `(user, organization)`. Without
`X-Organization-Id`, the call reads or writes the caller's pure-personal
instructions; with `X-Organization-Id` set, it operates on the user's
instructions specific to that organization.

The maximum length is **10,000 characters**.

<Note>
  These are the **caller's own** instructions. Use [Org Instructions](/cloud-api/configuration/org-instructions)
  to manage instructions that apply to every member of an organization.
</Note>

## GET /api/user/instructions

<Info>
  Required scope: `context:read`
</Info>

Read the caller's custom instructions for the current context.

### Headers

<ParamField header="Authorization" type="string" required>
  `Bearer <your_api_key>`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Optional. Selects user-instructions scoped to the given organization.
</ParamField>

### Response

<ResponseField name="instructions" type="string">
  The caller's custom instructions, or `null` if none have been set for this
  context.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the last update, or `null` if never set.
</ResponseField>

<RequestExample>
```bash cURL (read)
curl -X GET "https://app.runtm.com/api/user/instructions" \
  -H "Authorization: Bearer runtm_xxx"
```

```python Python (read)
import requests

response = requests.get(
    "https://app.runtm.com/api/user/instructions",
    headers={"Authorization": "Bearer runtm_xxx"},
)
print(response.json()["instructions"])
```

```javascript JavaScript (read)
const response = await fetch(
  "https://app.runtm.com/api/user/instructions",
  { headers: { Authorization: "Bearer runtm_xxx" } },
);
console.log((await response.json()).instructions);
```
</RequestExample>

<ResponseExample>
```json 200
{
  "instructions": "Always write tests using pytest.\nPrefer concise commit messages.",
  "updated_at": "2026-04-12T18:30:11Z"
}
```

```json 200 (none set)
{
  "instructions": null,
  "updated_at": null
}
```
</ResponseExample>

## PUT /api/user/instructions

<Info>
  Required scope: `context:write`
</Info>

Replace (or clear) the caller's custom instructions for the current context.

### Headers

<ParamField header="Authorization" type="string" required>
  `Bearer <your_api_key>`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Optional. Operates on the user-instructions scoped to the given organization.
</ParamField>

### Request Body

<ParamField body="instructions" type="string">
  Markdown instruction text (max 10,000 characters). Pass `null` or an empty
  string to clear the existing instructions.
</ParamField>

### Response

The same shape as `GET /api/user/instructions`, reflecting the updated value.

<RequestExample>
```bash cURL (write)
curl -X PUT "https://app.runtm.com/api/user/instructions" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "Content-Type: application/json" \
  -d '{"instructions": "Always write tests using pytest.\nPrefer concise commit messages."}'
```

```python Python (write)
import requests

response = requests.put(
    "https://app.runtm.com/api/user/instructions",
    headers={"Authorization": "Bearer runtm_xxx"},
    json={"instructions": "Always write tests using pytest."},
)
print(response.json())
```

```javascript JavaScript (write)
const response = await fetch(
  "https://app.runtm.com/api/user/instructions",
  {
    method: "PUT",
    headers: {
      Authorization: "Bearer runtm_xxx",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      instructions: "Always write tests using pytest.",
    }),
  },
);
console.log(await response.json());
```
</RequestExample>

<ResponseExample>
```json 200
{
  "instructions": "Always write tests using pytest.",
  "updated_at": "2026-05-09T22:14:00Z"
}
```

```json 422
{
  "detail": [
    {
      "type": "string_too_long",
      "loc": ["body", "instructions"],
      "msg": "String should have at most 10000 characters",
      "input": "..."
    }
  ]
}
```
</ResponseExample>

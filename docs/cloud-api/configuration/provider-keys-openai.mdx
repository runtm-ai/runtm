---
title: "OpenAI API Keys"
api: "/api/user/openai-key, /api/organizations/{org_id}/openai-key"
description: "Manage personal and organization-shared OpenAI API keys used by Codex-powered sessions. Values are never returned by any endpoint."
---

OpenAI keys are used by Codex agents and any other OpenAI-backed flows
inside sessions. The endpoints mirror the [Anthropic Key
endpoints](/cloud-api/configuration/provider-keys-anthropic) - only the path
and validation rule differ.

- **Personal OpenAI keys** - saved per `(user, organization)`.
- **Organization OpenAI keys** - set by org owners/admins, with the same
  `individual` / `enforced` policy as Anthropic.

To inspect which key would be used at session creation time, use
[Resolved Provider Keys](/cloud-api/configuration/provider-keys-resolved).

<Note>
  Values are never returned. Responses include only a masked preview
  (`sk-***xxxx`) and a "connected" / "has_key" flag. Treat keys as opaque,
  write-only values once stored.
</Note>

## Personal Key

### GET /api/user/openai-key

<Info>
  Required scope: `integrations:read`
</Info>

Read the caller's stored personal OpenAI key for the current context.

#### Headers

<ParamField header="Authorization" type="string" required>
  `Bearer <your_api_key>`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Optional. Reads the personal key scoped to the given organization.
</ParamField>

#### Response

<ResponseField name="connected" type="boolean">
  `true` if a personal key is configured.
</ResponseField>

<ResponseField name="key_preview" type="string">
  Masked preview of the stored key (e.g. `sk-***xxxx`), or `null` when none
  is set.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the last update, or `null` when never set.
</ResponseField>

<RequestExample>
```bash cURL (read)
curl -X GET "https://app.runtm.com/api/user/openai-key" \
  -H "Authorization: Bearer runtm_xxx"
```

```python Python (read)
import requests

response = requests.get(
    "https://app.runtm.com/api/user/openai-key",
    headers={"Authorization": "Bearer runtm_xxx"},
)
print(response.json())
```

```javascript JavaScript (read)
const response = await fetch(
  "https://app.runtm.com/api/user/openai-key",
  { headers: { Authorization: "Bearer runtm_xxx" } },
);
console.log(await response.json());
```
</RequestExample>

<ResponseExample>
```json 200 (connected)
{
  "connected": true,
  "key_preview": "sk-***WxYz",
  "updated_at": "2026-04-12T18:30:11Z"
}
```

```json 200 (not connected)
{
  "connected": false,
  "key_preview": null,
  "updated_at": null
}
```
</ResponseExample>

### PUT /api/user/openai-key

<Info>
  Required scope: `integrations:write`
</Info>

Save a personal OpenAI API key.

#### Headers

<ParamField header="Authorization" type="string" required>
  `Bearer <your_api_key>`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Optional. Stores the personal key against the given organization.
</ParamField>

#### Request Body

<ParamField body="api_key" type="string" required>
  OpenAI API key. Must start with `sk-`. Minimum 10 characters.
</ParamField>

#### Response

Same shape as `GET /api/user/openai-key`, with `connected: true`.

<RequestExample>
```bash cURL (write)
curl -X PUT "https://app.runtm.com/api/user/openai-key" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "Content-Type: application/json" \
  -d '{"api_key": "sk-..."}'
```

```python Python (write)
import requests

response = requests.put(
    "https://app.runtm.com/api/user/openai-key",
    headers={"Authorization": "Bearer runtm_xxx"},
    json={"api_key": "sk-..."},
)
print(response.json())
```

```javascript JavaScript (write)
const response = await fetch(
  "https://app.runtm.com/api/user/openai-key",
  {
    method: "PUT",
    headers: {
      Authorization: "Bearer runtm_xxx",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ api_key: "sk-..." }),
  },
);
console.log(await response.json());
```
</RequestExample>

<ResponseExample>
```json 200
{
  "connected": true,
  "key_preview": "sk-***WxYz",
  "updated_at": "2026-05-09T22:14:00Z"
}
```

```json 400
{
  "detail": "Invalid API key format. Key should start with 'sk-'"
}
```
</ResponseExample>

### DELETE /api/user/openai-key

<Info>
  Required scope: `integrations:write`
</Info>

Remove the caller's stored personal OpenAI key for the current context.

<ParamField header="Authorization" type="string" required>
  `Bearer <your_api_key>`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Optional. Removes the personal key scoped to the given organization.
</ParamField>

#### Response

Same shape as `GET /api/user/openai-key`, with `connected: false`.

<RequestExample>
```bash cURL (delete)
curl -X DELETE "https://app.runtm.com/api/user/openai-key" \

```


```javascript JavaScript (delete)
const response = await fetch(

    method: "DELETE",
    headers: { Authorization: "Bearer runtm_xxx" },
  },

```
</RequestExample>

<ResponseExample>
```json 200
{
  "connected": false,
  "key_preview": null,
```

</ResponseExample>

## Organization Key

<Warning>
  Setting and deleting the organization OpenAI key requires the caller to be
  an org **owner** or **admin**. Members with `integrations:write` on their
  key will still receive `403`.
</Warning>

<Note>
  Organization context is required. Set `X-Organization-Id` to match the
  path `org_id`, or use an org-scoped API key whose org ID matches.
</Note>

### GET /api/organizations/{org_id}/openai-key

<Info>
  Required scope: `integrations:read`
</Info>

All org members can read the key status.

#### Path Parameters

<ParamField path="org_id" type="string" required>
  Organization ID. Must match `X-Organization-Id` (or the API key's org).
</ParamField>

#### Response

<ResponseField name="organization_id" type="string">
  Echo of the path `org_id`.
</ResponseField>

<ResponseField name="has_key" type="boolean">
  `true` when the organization has a stored OpenAI key.
</ResponseField>

<ResponseField name="key_preview" type="string">
  Masked preview of the stored key, or `null` when none is set.
</ResponseField>

<ResponseField name="policy" type="string">
  `"individual"` (org key ignored) or `"enforced"` (org key used first).
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the last update, or `null` when never set.
</ResponseField>

<RequestExample>
```bash cURL (read)
curl -X GET "https://app.runtm.com/api/organizations/org_abc123/openai-key" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python (read)
import requests

response = requests.get(
    "https://app.runtm.com/api/organizations/org_abc123/openai-key",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)
print(response.json())
```

```javascript JavaScript (read)
const response = await fetch(
  "https://app.runtm.com/api/organizations/org_abc123/openai-key",
  {
    headers: {
      Authorization: "Bearer runtm_xxx",
      "X-Organization-Id": "org_abc123",
    },
  },
);
console.log(await response.json());
```
</RequestExample>

<ResponseExample>
```json 200
{
  "organization_id": "org_abc123",
  "has_key": true,
  "key_preview": "sk-***WxYz",
  "policy": "enforced",
  "updated_at": "2026-04-12T18:30:11Z"
}
```
</ResponseExample>

### PUT /api/organizations/{org_id}/openai-key

<Info>
  Required scope: `integrations:write`
</Info>

<Warning>
  Org owner or admin role required.
</Warning>

Set the organization OpenAI key, the active policy, or both.

#### Path Parameters

<ParamField path="org_id" type="string" required>
  Organization ID.
</ParamField>

#### Request Body

<ParamField body="api_key" type="string">
  OpenAI API key. Must start with `sk-` when provided. Required when
  switching to `policy="enforced"` for the first time.
</ParamField>

<ParamField body="policy" type="string">
  `"individual"` (default) or `"enforced"`.
</ParamField>

#### Response

Same shape as the GET response, reflecting the updated key and policy.

<RequestExample>
```bash cURL (set)
curl -X PUT "https://app.runtm.com/api/organizations/org_abc123/openai-key" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123" \
  -H "Content-Type: application/json" \
  -d '{"api_key": "sk-...", "policy": "enforced"}'
```

```python Python (set)
import requests

response = requests.put(
    "https://app.runtm.com/api/organizations/org_abc123/openai-key",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
    json={"api_key": "sk-...", "policy": "enforced"},
)
print(response.json())
```

```javascript JavaScript (set)
const response = await fetch(
  "https://app.runtm.com/api/organizations/org_abc123/openai-key",
  {
    method: "PUT",
    headers: {
      Authorization: "Bearer runtm_xxx",
      "X-Organization-Id": "org_abc123",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ api_key: "sk-...", policy: "enforced" }),
  },
);
console.log(await response.json());
```
</RequestExample>

<ResponseExample>
```json 200
{
  "organization_id": "org_abc123",
  "has_key": true,
  "key_preview": "sk-***WxYz",
  "policy": "enforced",
  "updated_at": "2026-05-09T22:14:00Z"
}
```

```json 400
{
  "detail": "Cannot set 'enforced' policy without an API key. Please provide an API key."
}
```
</ResponseExample>

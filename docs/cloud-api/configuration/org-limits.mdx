---
title: "Organization Limits"
api: "GET/PUT /api/organizations/{org_id}/limits"
description: "Read and write the organization's limit and policy configuration: per-member session caps, spend caps, allowed templates, and deployment policy."
---

Each organization has a single `limits` document used to enforce guardrails
across its members. The endpoint stores arbitrary key-value structures, but
only the keys listed below are recognised by the platform.

<Warning>
  Updating organization limits is restricted to organization **owners** and
  **admins**. Members with `guardrails:write` on their key still receive
  `403`.
</Warning>

<Note>
  Organization context is required. Set `X-Organization-Id` to the same
  value as the path `org_id`, or use an org-scoped API key whose org ID
  matches.
</Note>

## Recognised Keys

| Key | Type | Description |
|-----|------|-------------|
| `max_sessions_per_user` | integer | Max active sessions per member. |
| `max_cost_per_session` | float | Max USD cost allowed per session. |
| `max_daily_spend_per_user` | float | Max USD daily spend per member. |
| `max_monthly_spend_per_user` | float | Max USD monthly spend per member. |
| `allowed_templates` | array of strings or `null` | Allowed template names; `null` means all templates. |
| `enforcement` | `"soft"` or `"hard"` | `soft` shows warnings; `hard` blocks the action. |
| `deployment` | object | See **Deployment Policy** below. |

### Deployment Policy

| Field | Type | Description |
|-------|------|-------------|
| `mode` | `"all"` \| `"none"` \| `"per_role"` | Default policy. `all` permits everyone; `none` blocks everyone except owners; `per_role` follows `roles`. |
| `roles` | object | When `mode` is `"per_role"`, a map of `admin`/`member` booleans. |
| `user_grants` | array of strings | User IDs explicitly granted deploy access regardless of role policy. |

The decision flow is documented on [Check Deploy Permission](/cloud-api/configuration/deploy-permission).

## GET /api/organizations/{org_id}/limits

<Info>
  Required scope: `guardrails:read`
</Info>

Read the organization's current limits document.

### Path Parameters

<ParamField path="org_id" type="string" required>
  Organization ID. Must match `X-Organization-Id` (or the API key's org).
</ParamField>

### Headers

<ParamField header="Authorization" type="string" required>
  `Bearer <your_api_key>`
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  Required when using a personal API key. Must match `org_id`.
</ParamField>

### Response

<ResponseField name="organization_id" type="string">
  Echo of the path `org_id`.
</ResponseField>

<ResponseField name="limits" type="object">
  Recognised limit keys, or `{}` when none have been configured.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the last update, or `null` when never set.
</ResponseField>

<RequestExample>
```bash cURL (read)
curl -X GET "https://app.runtm.com/api/organizations/org_abc123/limits" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python (read)
import requests

response = requests.get(
    "https://app.runtm.com/api/organizations/org_abc123/limits",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)
print(response.json()["limits"])
```

```javascript JavaScript (read)
const response = await fetch(
  "https://app.runtm.com/api/organizations/org_abc123/limits",
  {
    headers: {
      Authorization: "Bearer runtm_xxx",
      "X-Organization-Id": "org_abc123",
    },
  },
);
console.log((await response.json()).limits);
```
</RequestExample>

<ResponseExample>
```json 200
{
  "organization_id": "org_abc123",
  "limits": {
    "max_sessions_per_user": 5,
    "max_cost_per_session": 25.0,
    "enforcement": "soft",
    "deployment": {
      "mode": "per_role",
      "roles": { "admin": true, "member": false }
    }
  },
  "updated_at": "2026-04-12T18:30:11Z"
}
```
</ResponseExample>

## PUT /api/organizations/{org_id}/limits

<Info>
  Required scope: `guardrails:write`
</Info>

<Warning>
  Org owner or admin role required.
</Warning>

Replace the entire limits document with the supplied object. Pass `{}` to
clear all limits.

### Path Parameters

<ParamField path="org_id" type="string" required>
  Organization ID. Must match `X-Organization-Id` (or the API key's org).
</ParamField>

### Headers

<ParamField header="Authorization" type="string" required>
  `Bearer <your_api_key>`
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  Required when using a personal API key. Must match `org_id`.
</ParamField>

### Request Body

<ParamField body="limits" type="object" required>
  An object using only the recognised keys above. Unknown keys cause `400`;
  invalid values for `enforcement`, `deployment.mode`, or
  `deployment.roles` also cause `400`.
</ParamField>

### Response

Same shape as the GET response, reflecting the new limits.

<RequestExample>
```bash cURL (write)
curl -X PUT "https://app.runtm.com/api/organizations/org_abc123/limits" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123" \
  -H "Content-Type: application/json" \
  -d '{
    "limits": {
      "max_sessions_per_user": 5,
      "enforcement": "hard",
      "deployment": {
        "mode": "per_role",
        "roles": { "admin": true, "member": false }
      }
    }
  }'
```

```python Python (write)
import requests

response = requests.put(
    "https://app.runtm.com/api/organizations/org_abc123/limits",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
    json={
        "limits": {
            "max_sessions_per_user": 5,
            "enforcement": "hard",
            "deployment": {
                "mode": "per_role",
                "roles": {"admin": True, "member": False},
            },
        }
    },
)
print(response.json())
```

```javascript JavaScript (write)
const response = await fetch(
  "https://app.runtm.com/api/organizations/org_abc123/limits",
  {
    method: "PUT",
    headers: {
      Authorization: "Bearer runtm_xxx",
      "X-Organization-Id": "org_abc123",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      limits: {
        max_sessions_per_user: 5,
        enforcement: "hard",
        deployment: {
          mode: "per_role",
          roles: { admin: true, member: false },
        },
      },
    }),
  },
);
console.log(await response.json());
```
</RequestExample>

<ResponseExample>
```json 200
{
  "organization_id": "org_abc123",
  "limits": {
    "max_sessions_per_user": 5,
    "enforcement": "hard",
    "deployment": {
      "mode": "per_role",
```

---
title: "Set Allowlist Policy"
api: "PUT /api/organizations/{org_id}/allowlist-policy"
description: "Set the default allowlist policy for an organization."
---

Updates the organization's default allowlist policy that controls how tools and commands are handled.

**Required scope:** `guardrails:write`

<ParamField path="org_id" type="string" required>
  The organization ID.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token. `Authorization: Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  Must match the `org_id` path parameter.
</ParamField>

<ParamField body="default_policy" type="string" required>
  The default policy. One of `allow`, `ask`, or `deny`.
</ParamField>

<ResponseField name="organization_id" type="string">
  The organization ID.
</ResponseField>

<ResponseField name="default_policy" type="string">
  The updated policy value.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the update.
</ResponseField>

<RequestExample>
```bash cURL
curl -X PUT "https://app.runtm.com/api/organizations/org_abc123/allowlist-policy" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123" \
  -H "Content-Type: application/json" \
  -d '{
    "default_policy": "deny"
  }'
```

```python Python
import requests

org_id = "org_abc123"

resp = requests.put(
    f"https://app.runtm.com/api/organizations/{org_id}/allowlist-policy",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": org_id,
        "Content-Type": "application/json",
    },
    json={"default_policy": "deny"},
)
print(resp.json())
```

```javascript JavaScript
const orgId = "org_abc123";

```

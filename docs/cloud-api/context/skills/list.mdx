---
title: "List Skills"
api: "GET /api/agent-directives"
description: "List skills, MCP servers, docs, hooks, and other agent directives"
---

Returns a paginated list of agent directives filtered by type family. Directives include skills, MCP servers, docs, network rules, allowlist rules, and hooks.

**Required scope:** `context:read`

## Query Parameters

<ParamField query="repo_full_name" type="string">
  Filter to directives attached to this repository (e.g. `owner/repo`).
</ParamField>

<ParamField query="type_family" type="string" default="skill">
  Filter by directive type family. Values: `skill`, `mcp_server`, `doc`, `network_rule`, `allowlist_rule`, `hook`.
</ParamField>

<ParamField query="page_size" type="integer" default="20">
  Number of results per page (1–100).
</ParamField>

<ParamField query="page_token" type="string">
  Opaque cursor from a previous response's `next_page_token`.
</ParamField>

<ParamField query="include_content" type="boolean" default="false">
  When `true`, each directive includes its full `content` field.
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Scope to an organization's directives.
</ParamField>

## Response

<ResponseField name="directives" type="array">
  Array of directive resources.
</ResponseField>

<ResponseField name="next_page_token" type="string | null">
  Cursor for the next page, or `null` if no more results.
</ResponseField>

<ResponseField name="total_size" type="integer">
  Total number of matching directives.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/agent-directives?type_family=skill&page_size=10" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/agent-directives",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
    params={
        "type_family": "skill",
        "page_size": 10,
        "include_content": False,
    },
)

data = response.json()
for d in data["directives"]:
    print(f"{d['name']} ({d['content_hash'][:12]})")
```

```javascript JavaScript

    },
  }
);

const data = await response.json();
data.directives.forEach((d) =>
  console.log(`${d.name} (${d.content_hash.slice(0, 12)})`)
);
```

---
title: "Create Skill"
api: "POST /api/agent-directives"
description: "Create a new agent directive (skill, MCP server, doc, hook, etc.)"
---

Creates a new agent directive. The directive starts as an unpublished draft - call [Publish](/cloud-api/context/skills/publish) to activate it.

**Required scope:** `context:write`

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Scope the directive to an organization.
</ParamField>

## Body

<ParamField body="type" type="string" required>
  Directive type: `skill_v0`, `mcp_server_v0`, `doc_v0`, `network_rule_v0`, `allowlist_rule_v0`, `hook_v0`.
</ParamField>

<ParamField body="name" type="string" required>
  Unique name (1–128 chars). For hooks, must be a slug: `^[a-z0-9][a-z0-9-]{0,63}$`.
</ParamField>

<ParamField body="display_name" type="string">
  Human-readable name shown in the UI.
</ParamField>

<ParamField body="description" type="string">
  Short description of what this directive does.
</ParamField>

<ParamField body="content" type="object" required>
  Type-specific content payload. Shape depends on `type` - see examples.
</ParamField>

## Response

Returns `201` with the created directive resource.

<ResponseField name="directive" type="object">
  The created directive resource with `id`, `version`, `is_published`, `content`, and timestamps.
</ResponseField>

```bash cURL
curl -X POST "https://app.runtm.com/api/agent-directives" \

  -d '{
    "type": "skill_v0",
    "name": "deploy-to-fly",
    "display_name": "Deploy to Fly.io",
    "description": "Guides the agent through Fly.io deployments",
    "content": {
      "entry_md": "SKILL.md",
      "files": [
        {
          "path": "SKILL.md",
          "inline": "# Deploy to Fly.io\n\nStep-by-step deployment guide..."
        }
      ]
    }
  }'
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/agent-directives",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
        "Content-Type": "application/json",
    },
    json={
        "type": "skill_v0",
        "name": "deploy-to-fly",
        "display_name": "Deploy to Fly.io",
        "description": "Guides the agent through Fly.io deployments",
        "content": {
            "entry_md": "SKILL.md",
            "files": [
                {
                    "path": "SKILL.md",
                    "inline": "# Deploy to Fly.io\n\nStep-by-step guide...",
                }
            ],
        },
    },
)

data = response.json()
print(f"Created: {data['directive']['id']}")
```

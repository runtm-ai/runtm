---
title: "Update Skill"
api: "PATCH /api/agent-directives/{directive_id}"
description: "Partially update a directive's metadata or content"
---

Updates one or more fields on a directive. Only provided fields are changed; omitted fields remain untouched.

**Required scope:** `context:write`

## Path Parameters

<ParamField path="directive_id" type="string" required>
  The directive ID (e.g. `dir_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Scope to an organization.
</ParamField>

## Body

<ParamField body="display_name" type="string">
  Updated human-readable name.
</ParamField>

<ParamField body="description" type="string">
  Updated description.
</ParamField>

<ParamField body="content" type="object">
  Updated content payload matching the directive's type.
</ParamField>

## Response

<ResponseField name="directive" type="object">
  The updated directive resource with full content included.
</ResponseField>

<RequestExample>
```bash cURL
curl -X PATCH "https://app.runtm.com/api/agent-directives/dir_abc123" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123" \
  -H "Content-Type: application/json" \
  -d '{
    "display_name": "Deploy to Fly.io (v2)",
    "description": "Updated deployment guide with GPU support"
  }'
```

```python Python
import requests

response = requests.patch(
    "https://app.runtm.com/api/agent-directives/dir_abc123",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
        "Content-Type": "application/json",
    },
    json={
        "display_name": "Deploy to Fly.io (v2)",
        "description": "Updated deployment guide with GPU support",
    },
)

data = response.json()
print(f"Updated: {data['directive']['display_name']}")
```

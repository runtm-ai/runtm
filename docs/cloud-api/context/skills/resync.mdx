---
title: "Resync Skill"
api: "POST /api/agent-directives/{directive_id}:resync"
description: "Re-fetch a directive's content from its upstream source"
---

Re-fetches the directive's content from its upstream source (for example a GitHub repo) and overwrites it in place. The directive keeps its id and its attachments, so everything already pointing at it picks up the new content; a rebuild is queued only when the content actually changed.

If the upstream payload is identical, nothing is written and the response carries `no_changes: true`. Locked directives cannot be resynced.

**Required scope:** `context:write`

## Path Parameters

<ParamField path="directive_id" type="string" required>
  The directive ID to resync (e.g. `dir_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Scope to an organization.
</ParamField>

## Body

No fields. Send an empty object; the shape is reserved for future options.

## Response

<ResponseField name="directive" type="object">
  The directive resource after the resync.
</ResponseField>

<ResponseField name="no_changes" type="boolean">
  `true` when the upstream content was identical and nothing was written.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/agent-directives/dir_abc123:resync" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123" \
  -H "Content-Type: application/json" \
  -d '{}'
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/agent-directives/dir_abc123:resync",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
        "Content-Type": "application/json",
    },
    json={},
)

data = response.json()
if data["no_changes"]:
    print("Already up to date")
else:
    print(f"Updated to {data['directive']['content_hash'][:12]}")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/agent-directives/dir_abc123:resync",
  {
    method: "POST",
    headers: {
      "Authorization": "Bearer runtm_xxx",
      "X-Organization-Id": "org_abc123",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({}),
  }
);

const data = await response.json();
if (data.no_changes) {
  console.log("Already up to date");
} else {
  console.log(`Updated to ${data.directive.content_hash.slice(0, 12)}`);
}
```

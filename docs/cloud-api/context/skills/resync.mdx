---
title: "Resync Skill"
api: "POST /api/agent-directives/{directive_id}:resync"
description: "Re-fetch a directive's upstream source and optionally auto-publish"
---

Re-fetches the directive's content from its upstream source (e.g. GitHub repo). If no changes are detected, only provenance timestamps are updated. If changes exist, a new version row is created.

When `auto_publish` is `true` and the previous version was already published, the new version is published atomically and inherits the old version's attachments.

**Required scope:** `context:write`

## Path Parameters

<ParamField path="directive_id" type="string" required>
  The directive ID to resync (e.g. `dir_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Scope to an organization.
</ParamField>

## Body

<ParamField body="auto_publish" type="boolean" default="false">
  When `true`, automatically publish the new version if the previous was published and changes were detected.
</ParamField>

## Response

<ResponseField name="directive" type="object">
  The directive resource (either updated existing or newly created version).
</ResponseField>

<ResponseField name="no_changes" type="boolean">
  `true` if upstream content was identical - no new version was created.
</ResponseField>

<ResponseField name="previous_version" type="integer">
  The version number that was current before the resync.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/agent-directives/dir_abc123:resync" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123" \
  -H "Content-Type: application/json" \
  -d '{"auto_publish": true}'
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/agent-directives/dir_abc123:resync",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
        "Content-Type": "application/json",
    },
    json={"auto_publish": True},
)

data = response.json()
if data["no_changes"]:
    print("Already up to date")
else:
    print(f"Updated to v{data['directive']['version']}")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/agent-directives/dir_abc123:resync",
  {
    method: "POST",
    headers: {
      "Authorization": "Bearer runtm_xxx",
      "X-Organization-Id": "org_abc123",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ auto_publish: true }),
  }
);

const data = await response.json();
if (data.no_changes) {
  console.log("Already up to date");
} else {
  console.log(`Updated to v${data.directive.version}`);
}
```

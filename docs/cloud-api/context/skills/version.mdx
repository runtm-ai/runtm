---
title: "New Version"
api: "POST /api/agent-directives/{directive_id}:new-version"
description: "Clone a directive into a new unpublished draft version"
---

Creates a new unpublished draft by cloning the specified directive. Idempotent - repeat calls return the same draft until it is published. Attachments are copied forward so publishing lands atomically without re-attaching.

**Required scope:** `context:write`

## Path Parameters

<ParamField path="directive_id" type="string" required>
  The directive ID to create a new version from (e.g. `dir_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Scope to an organization.
</ParamField>

## Response

Returns `201` with the new draft directive.

<ResponseField name="directive" type="object">
  The new draft directive resource. `is_published` will be `false` and `version` will be incremented.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/agent-directives/dir_abc123:new-version" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/agent-directives/dir_abc123:new-version",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)

data = response.json()
print(f"Draft v{data['directive']['version']}: {data['directive']['id']}")
```

---
title: "List Attachments"
api: "GET /api/agent-directives/{directive_id}/attachments"
description: "List the repository attachments for a directive"
---

Returns the list of repository attachments for a directive. Attachments determine which repositories a published directive is active in.

**Required scope:** `context:read`

## Path Parameters

<ParamField path="directive_id" type="string" required>
  The directive ID (e.g. `dir_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Scope to an organization.
</ParamField>

## Response

<ResponseField name="attachments" type="array">
  Array of attachment resources. Each contains `id`, `directive_id`, `directive_version`, `repo_full_name`, `applies_to_all`, `position`, and `created_at`.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/agent-directives/dir_abc123/attachments" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/agent-directives/dir_abc123/attachments",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)

data = response.json()
for att in data["attachments"]:
    if att["applies_to_all"]:
        print("  Applies to all repos")
    else:
        print(f"  {att['repo_full_name']}")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/agent-directives/dir_abc123/attachments",
  {
    headers: {
      "Authorization": "Bearer runtm_xxx",

const data = await response.json();
data.attachments.forEach((att) => {
  if (att.applies_to_all) {
    console.log("  Applies to all repos");
  } else {
    console.log(`  ${att.repo_full_name}`);
  }
});
```

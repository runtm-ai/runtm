---
title: "Get Skill"
api: "GET /api/agent-directives/{directive_id}"
description: "Retrieve a single agent directive by ID"
---

Returns the full details of a single agent directive, optionally including its content.

**Required scope:** `context:read`

## Path Parameters

<ParamField path="directive_id" type="string" required>
  The directive ID (e.g. `dir_abc123`).
</ParamField>

## Query Parameters

<ParamField query="include_content" type="boolean" default="false">
  When `true`, includes the full `content` payload in the response.
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Scope to an organization.
</ParamField>

## Response

<ResponseField name="directive" type="object">
  The directive resource with metadata, source provenance, and attachment summary.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/agent-directives/dir_abc123?include_content=true" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/agent-directives/dir_abc123",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
    params={"include_content": True},
)

data = response.json()
directive = data["directive"]
print(f"{directive['name']} v{directive['version']}")
```


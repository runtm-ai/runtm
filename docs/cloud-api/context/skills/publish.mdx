---
title: "Publish Skill"
api: "POST /api/agent-directives/{directive_id}:publish"
description: "Publish the current draft version of a directive"
---

Publishes the current draft of a directive, making it active for all attached repositories. Previous published versions are superseded.

**Required scope:** `context:write`

## Path Parameters

<ParamField path="directive_id" type="string" required>
  The directive ID to publish (e.g. `dir_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Scope to an organization.
</ParamField>

## Response

<ResponseField name="directive" type="object">
  The published directive resource with `is_published: true`.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/agent-directives/dir_abc123:publish" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/agent-directives/dir_abc123:publish",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)

data = response.json()
print(f"Published: {data['directive']['is_published']}")
```

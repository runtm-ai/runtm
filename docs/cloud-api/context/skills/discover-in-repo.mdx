---
title: "Discover Skills in Repo"
api: "POST /api/agent-directives:discover-in-repo"
description: "Scan a GitHub repository for SKILL.md candidates"
---

Scans a GitHub repository tree for every `SKILL.md` file and returns candidates the UI can render for user selection. Read-only — no directives are created.

**Required scope:** `context:read`

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Scope to an organization (uses the org's GitHub App installation for repo access).
</ParamField>

## Body

<ParamField body="repo" type="string" required>
  GitHub repository in `owner/repo` format (3–256 chars).
</ParamField>

<ParamField body="ref" type="string">
  Git ref to scan (branch, tag, or SHA). Defaults to the repo's default branch.
</ParamField>

## Response

<ResponseField name="repo" type="string">
  The repository that was scanned.
</ResponseField>

<ResponseField name="ref" type="string | null">
  The ref that was resolved.
</ResponseField>

<ResponseField name="commit_sha" type="string">
  The commit SHA at the time of scanning.
</ResponseField>

<ResponseField name="candidates" type="array">
  Array of skill candidates found in the repo. Each includes `path`, `dir`, `name`, `display_name`, `description`, `size_bytes`, `frontmatter`, and `already_imported`.
</ResponseField>

<ResponseField name="truncated" type="boolean">
  `true` if the scan hit the maximum number of candidates.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/agent-directives:discover-in-repo" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123" \
  -H "Content-Type: application/json" \
  -d '{"repo": "acme/my-skills", "ref": "main"}'
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/agent-directives:discover-in-repo",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
        "Content-Type": "application/json",
    },
    json={"repo": "acme/my-skills", "ref": "main"},
)

data = response.json()
for c in data["candidates"]:
    status = "imported" if c["already_imported"] else "new"
    print(f"  {c['path']} ({status})")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/agent-directives:discover-in-repo",
  {
    method: "POST",
    headers: {
      "Authorization": "Bearer runtm_xxx",
      "X-Organization-Id": "org_abc123",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ repo: "acme/my-skills", ref: "main" }),
  }
);

const data = await response.json();
data.candidates.forEach((c) => {
  const status = c.already_imported ? "imported" : "new";
  console.log(`  ${c.path} (${status})`);
});
```

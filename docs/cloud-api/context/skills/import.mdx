---
title: "Import Skill"
api: "POST /api/agent-directives:import"
description: "Import one or more directives from a URL or GitHub repository"
---

Imports directives from an external source. Supports GitHub repos (importing multiple skills at once via `paths`) and individual URLs. Optionally attach to repositories and publish in a single call.

**Required scope:** `context:write`

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Scope to an organization.
</ParamField>

## Body

<ParamField body="source_kind" type="string" required>
  Source type: `github_repo`, `github_url`, or `url`.
</ParamField>

<ParamField body="uri" type="string" required>
  Source URI. For `github_repo`: `owner/repo`. For URLs: full URL to a `SKILL.md` file.
</ParamField>

<ParamField body="ref" type="string">
  Git ref for GitHub sources (branch, tag, or SHA).
</ParamField>

<ParamField body="attach" type="object">
  Optional attachment config applied to each imported directive. Contains `repo_full_names` (array of `owner/repo`) and `applies_to_all` (boolean).
</ParamField>

<ParamField body="publish" type="boolean" default="false">
  When `true`, publish each imported directive immediately.
</ParamField>

<ParamField body="paths" type="array">
  For `github_repo` source: specific `SKILL.md` paths to import. If omitted, all discovered skills are imported.
</ParamField>

## Response

<ResponseField name="directives" type="array">
  Array of imported directive resources.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/agent-directives:import" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123" \
  -H "Content-Type: application/json" \
  -d '{
    "source_kind": "github_repo",
    "uri": "acme/my-skills",
    "ref": "main",
    "paths": [".claude/skills/deploy-to-fly/SKILL.md"],
    "attach": {
      "repo_full_names": ["acme/web-app"],
      "applies_to_all": false
    },
    "publish": true
  }'
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/agent-directives:import",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
        "Content-Type": "application/json",
    },
    json={
        "source_kind": "github_repo",
        "uri": "acme/my-skills",
        "ref": "main",
        "paths": [".claude/skills/deploy-to-fly/SKILL.md"],
        "publish": True,
    },
)

data = response.json()
for d in data["directives"]:
    print(f"Imported: {d['name']} (v{d['version']})")
```

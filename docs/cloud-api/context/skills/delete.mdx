---
title: "Delete Skill"
api: "DELETE /api/agent-directives/{directive_id}"
description: "Soft-delete an agent directive"
---

Deletes an agent directive. The directive is soft-deleted and no longer appears in list results or template builds.

**Required scope:** `context:write`

## Path Parameters

<ParamField path="directive_id" type="string" required>
  The directive ID (e.g. `dir_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Scope to an organization.
</ParamField>

## Response

Returns `204 No Content` on success.

<RequestExample>
```bash cURL
curl -X DELETE "https://app.runtm.com/api/agent-directives/dir_abc123" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

response = requests.delete(
    "https://app.runtm.com/api/agent-directives/dir_abc123",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)

assert response.status_code == 204
```


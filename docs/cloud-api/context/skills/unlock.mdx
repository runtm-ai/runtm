---
title: "Unlock Directive"
api: "POST /api/agent-directives/{directive_id}:unlock"
description: "Unlock a locked skill or MCP server"
---

Removes the lock so the directive can be edited, deleted, resynced, and reattached again.

**Required scope:** `context:write`, and the caller must be an org admin or owner.

## Path Parameters

<ParamField path="directive_id" type="string" required>
  The directive ID.
</ParamField>

## Response

<ResponseField name="directive" type="object">
  The updated directive, with `locked: false`.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/cloud/agent-directives/dir_9f3c1a:unlock" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```bash CLI
runtm-api skills unlock dir_9f3c1a
```
</RequestExample>

<ResponseExample>
```json 200
{
  "directive": {
    "id": "dir_9f3c1a",
    "type": "skill_v0",
    "name": "outbound-writing",
    "locked": false,
    "locked_by_user_id": null,
    "locked_at": null
  }
}
```
</ResponseExample>

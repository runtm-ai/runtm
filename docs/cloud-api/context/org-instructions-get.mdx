---
title: "Get Org Instructions"
api: "GET /api/organizations/{org_id}/instructions"
description: "Retrieve the custom instructions set for an organization."
---

Returns the organization's shared custom instructions that apply to all members.

**Required scope:** `context:read`

<Note>The `X-Organization-Id` header must match the `org_id` path parameter.</Note>

<ParamField path="org_id" type="string" required>
  The organization ID.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token. `Authorization: Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  Must match the `org_id` path parameter.
</ParamField>

<ResponseField name="organization_id" type="string">
  The organization ID.
</ResponseField>

<ResponseField name="instructions" type="string">
  The organization's custom instructions text. Null if none set.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the last update. Null if never set.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/cloud/organizations/org_abc123/instructions" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

org_id = "org_abc123"

resp = requests.get(
    f"https://app.runtm.com/api/cloud/organizations/{org_id}/instructions",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": org_id,
    },
)
print(resp.json())
```

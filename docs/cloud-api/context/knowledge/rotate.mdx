---
title: "Rotate Credentials"
api: "POST /api/knowledge/integrations/{integration_id}:rotate"
description: "Replace the credentials on a knowledge integration."
---

Replaces the stored credentials for a static-auth knowledge integration.
You can optionally switch to a different auth method on the same provider in the same call.

For OAuth-connected integrations, re-run the [OAuth Install](/cloud-api/context/knowledge/oauth-install) flow instead.

**Required scope:** `integrations:write`

<Note>Requires organization context via the `X-Organization-Id` header.</Note>

<ParamField path="integration_id" type="string" required>
  The integration whose credentials to rotate.
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  The organization the integration belongs to.
</ParamField>

<ParamField body="auth_method" type="string" required>
  Auth method identifier. Must be a valid static method for this provider.
</ParamField>

<ParamField body="credentials" type="object" required>
  New credential payload matching the auth method's `credential_schema`. Never returned in responses.
</ParamField>

<ParamField body="provider_metadata" type="object">
  Optional replacement provider-specific configuration.
</ParamField>

<ResponseField name="integration" type="KnowledgeIntegrationResource" required>
  The updated integration resource. See [List](/cloud-api/context/knowledge/list) for the full resource shape.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST https://app.runtm.com/api/knowledge/integrations/ki_01J...:rotate \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123" \
  -H "Content-Type: application/json" \
  -d '{
    "auth_method": "service_account",
    "credentials": {
      "service_account_json": "{...new key...}"
    }
  }'
```

```python Python
import requests

integration_id = "ki_01J..."

resp = requests.post(
    f"https://app.runtm.com/api/knowledge/integrations/{integration_id}:rotate",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
        "Content-Type": "application/json",
    },
    json={
        "auth_method": "service_account",
        "credentials": {"service_account_json": "{...new key...}"},
    },
)
print(resp.json())
```


---
title: "Update Knowledge Integration"
api: "PATCH /api/knowledge/integrations/{integration_id}"
description: "Update display name, metadata, or tool permissions on an integration."
---

Partially updates a knowledge integration. Only the fields you include in the body are changed; omitted fields are left untouched.

This endpoint does **not** update credentials — use [Rotate Credentials](/cloud-api/context/knowledge/rotate) for that.

**Required scope:** `integrations:write`

<Note>Requires organization context via the `X-Organization-Id` header.</Note>

<ParamField path="integration_id" type="string" required>
  The integration ID to update.
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  The organization the integration belongs to.
</ParamField>

<ParamField body="display_name" type="string">
  New display name (max 200 characters).
</ParamField>

<ParamField body="provider_metadata" type="object">
  Replacement provider-specific configuration.
</ParamField>

<ParamField body="default_mode" type="string">
  Default tool permission mode: `"auto"`, `"allow"`, or `"ask"`.
</ParamField>

<ParamField body="tool_permissions" type="object">
  Per-tool permission overrides. Keys are tool IDs, values are `"auto"`, `"allow"`, or `"ask"`.
</ParamField>

<ResponseField name="integration" type="KnowledgeIntegrationResource" required>
  The updated integration resource. See [List](/cloud-api/context/knowledge/list) for the full resource shape.
</ResponseField>

<RequestExample>
```bash cURL
curl -X PATCH https://app.runtm.com/api/knowledge/integrations/ki_01J... \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123" \
  -H "Content-Type: application/json" \
  -d '{
    "display_name": "Prod warehouse (read-only)",
    "default_mode": "ask",
    "tool_permissions": {
      "query": "allow"
    }
  }'
```

```python Python
import requests

integration_id = "ki_01J..."

resp = requests.patch(
    f"https://app.runtm.com/api/knowledge/integrations/{integration_id}",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
        "Content-Type": "application/json",
    },
    json={
        "display_name": "Prod warehouse (read-only)",
        "default_mode": "ask",
        "tool_permissions": {"query": "allow"},
    },
)
print(resp.json())
```

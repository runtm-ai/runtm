---
title: "Test Knowledge Integration"
api: "POST /api/knowledge/integrations/{integration_id}:test"
description: "Run a connectivity check against a knowledge integration."
---

Tests the stored credentials for a knowledge integration by making a lightweight call to the upstream provider.
Returns the integration resource along with a health check result.

**Required scope:** `integrations:read`

<Note>Requires organization context via the `X-Organization-Id` header.</Note>

<ParamField path="integration_id" type="string" required>
  The integration to test.
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  The organization the integration belongs to.
</ParamField>

<ResponseField name="integration" type="KnowledgeIntegrationResource" required>
  The integration resource. See [List](/cloud-api/context/knowledge/list) for the full resource shape.
</ResponseField>

<ResponseField name="ok" type="boolean" required>
  `true` if the connectivity check succeeded.
</ResponseField>

<ResponseField name="detail" type="string">
  Human-readable explanation when `ok` is `false`, or `null` on success.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST https://app.runtm.com/api/knowledge/integrations/ki_01J...:test \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

integration_id = "ki_01J..."

resp = requests.post(
    f"https://app.runtm.com/api/knowledge/integrations/{integration_id}:test",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)
print(resp.json())
```

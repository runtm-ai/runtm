---
title: "Get Knowledge Integration"
api: "GET /api/knowledge/integrations/{integration_id}"
description: "Retrieve a single knowledge integration by ID."
---

Returns the full resource for a specific knowledge integration.

**Required scope:** `integrations:read`

<Note>Requires organization context via the `X-Organization-Id` header.</Note>

<ParamField path="integration_id" type="string" required>
  The integration ID to retrieve.
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  The organization the integration belongs to.
</ParamField>

<ResponseField name="integration" type="KnowledgeIntegrationResource" required>
  The integration resource. See [List](/cloud-api/context/knowledge/list) for the full resource shape.
</ResponseField>

<RequestExample>
```bash cURL
curl https://app.runtm.com/api/knowledge/integrations/ki_01J... \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

integration_id = "ki_01J..."

resp = requests.get(
    f"https://app.runtm.com/api/knowledge/integrations/{integration_id}",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)
print(resp.json())
```

```javascript JavaScript
const integrationId = "ki_01J...";

  `https://app.runtm.com/api/knowledge/integrations/${integrationId}`,

    },
  }
```

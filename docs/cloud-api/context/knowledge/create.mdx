---
title: "Create Knowledge Integration"
api: "POST /api/knowledge/integrations"
description: "Connect a new knowledge provider with static credentials."
---

Creates a knowledge integration for the current organization using a static auth method.
For OAuth-based providers, use the [OAuth Install](/cloud-api/context/knowledge/oauth-install) endpoint instead.

**Required scope:** `integrations:write`

<Note>Requires organization context via the `X-Organization-Id` header.</Note>

<ParamField header="X-Organization-Id" type="string" required>
  The organization to create the integration in.
</ParamField>

<ParamField body="provider" type="string" required>
  Provider identifier from the [catalog](/cloud-api/context/knowledge/catalog) (e.g. `"bigquery"`).
</ParamField>

<ParamField body="auth_method" type="string" required>
  Auth method identifier from the provider's catalog entry (e.g. `"service_account"`).
</ParamField>

<ParamField body="scope" type="string" default="org">
  `"org"` for a shared integration or `"personal"` for a user-scoped one.
</ParamField>

<ParamField body="display_name" type="string">
  Optional human-readable name (max 200 characters).
</ParamField>

<ParamField body="credentials" type="object" required>
  Credential payload matching the auth method's `credential_schema`. Never returned in responses.
</ParamField>

<ParamField body="provider_metadata" type="object" default="{}">
  Provider-specific configuration (e.g. `{ "project_id": "my-gcp-project" }`).
</ParamField>

<ParamField body="default_mode" type="string">
  Default tool permission mode: `"auto"`, `"allow"`, or `"ask"`.
</ParamField>

<ResponseField name="integration" type="KnowledgeIntegrationResource" required>
  The newly created integration. See [List](/cloud-api/context/knowledge/list) for the full resource shape.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST https://app.runtm.com/api/knowledge/integrations \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "bigquery",
    "auth_method": "service_account",
    "scope": "org",
    "display_name": "Production warehouse",
    "credentials": {
      "service_account_json": "{...}"
    },
    "provider_metadata": {
      "project_id": "my-gcp-project"
    }
  }'
```

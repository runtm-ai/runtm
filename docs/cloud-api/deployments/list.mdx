---
title: "List Deployments"
api: "GET /api/v0/deployments"
description: "List the deployments created from sessions"
---

Lists deployments, newest first. These are the deployments `session deploy run` produces; each carries its live URL, state, and version chain.

**Required scope:** `deployments:read` (API key auth)

## Query Parameters

<ParamField query="state" type="string">
  Filter by state: `queued`, `building`, `deploying`, `ready`, `failed`, `destroyed`.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Results per page (1 to 100).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Pagination offset.
</ParamField>

## Response

<ResponseField name="deployments" type="array">
  Deployment objects: `{deployment_id, name, state, url, error_message, version, is_latest, previous_deployment_id, app_name, template, runtime, src_hash, created_at, updated_at, ready_at, discovery}`.
</ResponseField>

<ResponseField name="total" type="integer">
  Total matches before paging.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/cloud/v0/deployments?state=ready" \
  -H "Authorization: Bearer runtm_xxx"
```

```bash CLI
runtm-api deployments list --state ready
```
</RequestExample>

---
title: "Get Deployment"
api: "GET /api/v0/deployments/{deployment_id}"
description: "Get one deployment"
---

Returns a single deployment with its state, live URL, and version chain.

**Required scope:** `deployments:read` (API key auth)

## Path Parameters

<ParamField path="deployment_id" type="string" required>
  The deployment ID.
</ParamField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/cloud/v0/deployments/dep_3f2a" \
  -H "Authorization: Bearer runtm_xxx"
```

```bash CLI
runtm-api deployments get dep_3f2a
```
</RequestExample>

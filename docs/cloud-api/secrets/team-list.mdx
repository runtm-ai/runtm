---
title: "List Team Secrets"
api: "GET /api/secrets/team"
description: "List team secret names for the organization"
---

Returns names of team (organization-scoped) secrets. Admins see names and descriptions; members see names only. Values are never returned. Requires `X-Organization-Id` header.

**Required scope:** `secrets:read`

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  Organization ID. Required for team secrets.
</ParamField>

## Response

<ResponseField name="secrets" type="array">
  Array of team secret entries.
</ResponseField>

<ResponseField name="secrets[].name" type="string">
  Secret name.
</ResponseField>

<ResponseField name="secrets[].has_value" type="boolean">
  Always `true` for team secrets.
</ResponseField>

<ResponseField name="secrets[].description" type="string | null">
  Description (visible to admins only).
</ResponseField>

<ResponseField name="count" type="integer">
  Total number of team secrets.
</ResponseField>

<ResponseField name="is_admin" type="boolean">
  Whether the requesting user has admin role.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/cloud/secrets/team" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/cloud/secrets/team",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)

data = response.json()
print(f"Team secrets: {data['count']} (admin={data['is_admin']})")
for secret in data["secrets"]:
    print(f"  {secret['name']}")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/cloud/secrets/team",
  {
    headers: {
      "Authorization": "Bearer runtm_xxx",

    },
  }

const data = await response.json();
console.log(`Team secrets: ${data.count} (admin=${data.is_admin})`);
data.secrets.forEach((s) => console.log(`  ${s.name}`));
```

---
title: "List Personal Secrets"
api: "GET /api/secrets/personal"
description: "List personal secret names and metadata"
---

Returns names and metadata for the authenticated user's personal secrets. Values are never returned - only names and whether a value is set.

**Required scope:** `secrets:read`

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Optional org context. Personal secrets are user-scoped but may be org-aware.
</ParamField>

## Response

<ResponseField name="secrets" type="array">
  Array of secret entries.
</ResponseField>

<ResponseField name="secrets[].name" type="string">
  Secret name.
</ResponseField>

<ResponseField name="secrets[].has_value" type="boolean">
  Whether the secret has a stored value.
</ResponseField>

<ResponseField name="secrets[].description" type="string | null">
  Optional description of the secret.
</ResponseField>

<ResponseField name="secrets[].source" type="string | null">
  Source of the secret (e.g. `personal`).
</ResponseField>

<ResponseField name="count" type="integer">
  Total number of personal secrets.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/cloud/secrets/personal" \
  -H "Authorization: Bearer runtm_xxx"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/cloud/secrets/personal",
    headers={"Authorization": "Bearer runtm_xxx"},
)

data = response.json()
for secret in data["secrets"]:
    print(f"{secret['name']} (set={secret['has_value']})")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/cloud/secrets/personal",
  {
    headers: {
      "Authorization": "Bearer runtm_xxx",
    },
  }
);

const data = await response.json();
data.secrets.forEach((s) =>
  console.log(`${s.name} (set=${s.has_value})`)
);
```
</RequestExample>

---
title: "Set Team Secret"
api: "PUT /api/secrets/team"
description: "Create or update team secrets for the organization"
---

Bulk upserts team (organization-scoped) secrets. Values are encrypted before storage and can never be read back. Requires admin or owner role and `X-Organization-Id` header.

**Required scope:** `secrets:write`

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  Organization ID. Required for team secrets.
</ParamField>

## Body

<ParamField body="secrets" type="array" required>
  Array of secret objects to upsert.
</ParamField>

<ParamField body="secrets[].name" type="string" required>
  Secret name (max 255 characters).
</ParamField>

<ParamField body="secrets[].value" type="string" required>
  Secret value (1–10240 characters). Encrypted before storage.
</ParamField>

<ParamField body="secrets[].description" type="string">
  Optional description (max 500 characters).
</ParamField>

## Response

<ResponseField name="status" type="string">
  Operation result (`ok`).
</ResponseField>

<ResponseField name="count" type="integer">
  Number of secrets upserted.
</ResponseField>

<RequestExample>
```bash cURL

  -H "Authorization: Bearer runtm_xxx" \

  -d '{
    "secrets": [

      },

        "name": "STRIPE_SECRET_KEY",
        "value": "sk_live_abc123...",
        "description": "Stripe API secret key"
      }
    ]
  }'
```

```python Python
import requests

response = requests.put(
    "https://app.runtm.com/api/secrets/team",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
        "Content-Type": "application/json",
    },
    json={
        "secrets": [
            {
                "name": "DATABASE_URL",
                "value": "postgres://user:pass@host:5432/prod",
                "description": "Production database",
            },
            {
                "name": "STRIPE_SECRET_KEY",
                "value": "sk_live_abc123...",
                "description": "Stripe API secret key",
            },
        ]
    },
)

data = response.json()
print(f"Set {data['count']} team secrets")
```

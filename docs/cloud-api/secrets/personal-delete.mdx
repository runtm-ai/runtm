---
title: "Delete Personal Secret"
api: "DELETE /api/secrets/personal/{name}"
description: "Delete a personal secret by name"
---

Deletes a single personal secret by its key name.

**Required scope:** `secrets:write`

## Path Parameters

<ParamField path="name" type="string" required>
  The secret name to delete (e.g. `OPENAI_API_KEY`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Optional org context.
</ParamField>

## Response

<ResponseField name="status" type="string">
  Operation result (`ok`).
</ResponseField>

<ResponseField name="deleted" type="string">
  Name of the deleted secret.
</ResponseField>

<RequestExample>
```bash cURL
curl -X DELETE "https://app.runtm.com/api/secrets/personal/OPENAI_API_KEY" \
  -H "Authorization: Bearer runtm_xxx"
```

```python Python
import requests

response = requests.delete(
    "https://app.runtm.com/api/secrets/personal/OPENAI_API_KEY",
    headers={"Authorization": "Bearer runtm_xxx"},
)

data = response.json()
print(f"Deleted: {data['deleted']}")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/secrets/personal/OPENAI_API_KEY",
  {
    method: "DELETE",
    headers: {
      "Authorization": "Bearer runtm_xxx",
    },
  }
);

const data = await response.json();
console.log(`Deleted: ${data.deleted}`);
```
</RequestExample>

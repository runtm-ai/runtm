---
title: "Set Personal Secret"
api: "PUT /api/secrets/personal"
description: "Create or update personal secrets"
---

Bulk upserts personal secrets. Values are encrypted before storage and can never be read back - this is a write-only operation. Existing secrets with the same name are overwritten.

**Required scope:** `secrets:write`

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Optional org context.
</ParamField>

## Body

<ParamField body="secrets" type="array" required>
  Array of secret objects to upsert.
</ParamField>

<ParamField body="secrets[].name" type="string" required>
  Secret name (max 255 characters).
</ParamField>

<ParamField body="secrets[].value" type="string" required>
  Secret value (1–10240 characters). Encrypted before storage.
</ParamField>

<ParamField body="secrets[].description" type="string">
  Optional description (max 500 characters).
</ParamField>

## Response

<ResponseField name="status" type="string">
  Operation result (`ok`).
</ResponseField>

<ResponseField name="count" type="integer">
  Number of secrets upserted.
</ResponseField>

<RequestExample>
```bash cURL
curl -X PUT "https://app.runtm.com/api/secrets/personal" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "secrets": [
      {
        "name": "OPENAI_API_KEY",
        "value": "sk-proj-abc123...",
        "description": "OpenAI API key for GPT models"
      }
    ]
  }'
```

```python Python
import requests

response = requests.put(
    "https://app.runtm.com/api/secrets/personal",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "Content-Type": "application/json",
    },
    json={
        "secrets": [
            {
                "name": "OPENAI_API_KEY",
                "value": "sk-proj-abc123...",
                "description": "OpenAI API key for GPT models",
            }
        ]
    },
)

data = response.json()
print(f"Set {data['count']} secrets")
```

```javascript JavaScript

console.log(`Set ${data.count} secrets`);
```

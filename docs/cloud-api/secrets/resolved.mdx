---
title: "Resolved Secrets"
api: "GET /api/secrets/resolved"
description: "Get merged secret names from personal and team sources"
---

Returns the merged list of secret names from both personal and team sources with source indicators. When a secret exists in both personal and team scopes, team wins. Values are never returned.

**Required scope:** `secrets:read`

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Organization ID. When set, team secrets are included in resolution.
</ParamField>

## Response

<ResponseField name="secrets" type="array">
  Array of resolved secret entries with source information.
</ResponseField>

<ResponseField name="secrets[].name" type="string">
  Secret name.
</ResponseField>

<ResponseField name="secrets[].source" type="string">
  Where the secret comes from: `personal` or `team`. When both exist, `team` takes precedence.
</ResponseField>

<ResponseField name="count" type="integer">
  Total number of resolved secrets.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/secrets/resolved" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/secrets/resolved",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)

data = response.json()
for secret in data["secrets"]:
    print(f"{secret['name']} (source: {secret['source']})")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/secrets/resolved",
  {
    headers: {
      "Authorization": "Bearer runtm_xxx",
      "X-Organization-Id": "org_abc123",
    },
  }
);

const data = await response.json();
data.secrets.forEach((s) =>
  console.log(`${s.name} (source: ${s.source})`)
);
```

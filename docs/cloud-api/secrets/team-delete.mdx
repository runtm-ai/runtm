---
title: "Delete Team Secret"
api: "DELETE /api/secrets/team/{name}"
description: "Delete a team secret by name"
---

Deletes a single team (organization-scoped) secret by its key name. Requires admin or owner role and `X-Organization-Id` header.

**Required scope:** `secrets:write`

## Path Parameters

<ParamField path="name" type="string" required>
  The secret name to delete (e.g. `DATABASE_URL`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  Organization ID. Required for team secrets.
</ParamField>

## Response

<ResponseField name="status" type="string">
  Operation result (`ok`).
</ResponseField>

<ResponseField name="deleted" type="string">
  Name of the deleted secret.
</ResponseField>

<RequestExample>
```bash cURL
curl -X DELETE "https://app.runtm.com/api/secrets/team/DATABASE_URL" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

response = requests.delete(
    "https://app.runtm.com/api/secrets/team/DATABASE_URL",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
)

data = response.json()
print(f"Deleted: {data['deleted']}")
```


</RequestExample>

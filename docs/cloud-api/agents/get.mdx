---
title: "Get Agent"
api: "GET /api/v1/agents/{agent_id}"
description: "Get one roster agent"
---

Returns a single [agent object](/cloud-api/agents/overview#the-agent-object). Agents outside the caller's organization return `404`.

**Required scope:** `activity:read`

## Path Parameters

<ParamField path="agent_id" type="string" required>
  The agent ID.
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token.
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Organization ID. Omit for personal agents.
</ParamField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/cloud/v1/agents/a1b2c3d4-0000-0000-0000-000000000000" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```bash CLI
runtm-api agents get a1b2c3d4-0000-0000-0000-000000000000
```
</RequestExample>

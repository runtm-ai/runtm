---
title: "List Agents"
api: "GET /api/v1/agents"
description: "List the organization's roster agents"
---

Returns every agent in the active organization as a JSON array. The list lazily syncs rows from trigger integrations that carry a `config.agent_id`, so agents created through the dashboard's trigger flows appear here without a separate backfill.

**Required scope:** `activity:read`

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Organization ID. Omit for personal agents.
</ParamField>

## Response

A JSON array of [agent objects](/cloud-api/agents/overview#the-agent-object).

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/cloud/v1/agents" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```bash CLI
runtm-api agents list
```
</RequestExample>

---
title: "List Trigger Credentials"
api: "GET /api/v1/agents/trigger-credentials"
description: "Referencable agent trigger tokens (metadata only, never the secret)"
---

Lists the trigger credentials each agent exposes for use as credential placeholders. The `ref` value is what a connection stores instead of a raw secret (for example `agent["<id>"]["slack_bot_token"]`); the overlay loaders dereference it at session boot. Returns an empty list without an organization context.

**Required scope:** `integrations:read`

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token.
</ParamField>

<ParamField header="X-Organization-Id" type="string" required>
  Organization ID.
</ParamField>

## Response

<ResponseField name="trigger_credentials" type="array">
  <Expandable title="properties">
    <ResponseField name="ref" type="string">
      The placeholder a connection stores as a credential value.
    </ResponseField>
    <ResponseField name="agent_id" type="string">
      The roster agent exposing the credential.
    </ResponseField>
    <ResponseField name="agent_name" type="string">
      Agent display name.
    </ResponseField>
    <ResponseField name="provider" type="string">
      Trigger platform, for example `slack`.
    </ResponseField>
    <ResponseField name="credential_key" type="string">
      Which credential of the integration this references, for example `slack_bot_token`.
    </ResponseField>
    <ResponseField name="integration_id" type="string">
      The trigger integration carrying the actual secret.
    </ResponseField>
    <ResponseField name="integration_name" type="string | null">
      Trigger integration display name.
    </ResponseField>
  </Expandable>
</ResponseField>

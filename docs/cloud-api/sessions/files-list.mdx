---
title: "List Files"
api: "GET /api/sessions/{session_id}/files"
description: "List files and directories in the session sandbox"
---

Returns a list of files and directories at the given path in the sandbox.

**Required scope:** `sessions:read`

## Path Parameters

<ParamField path="session_id" type="string" required>
  The session ID (e.g. `ses_abc123`).
</ParamField>

## Query Parameters

<ParamField query="path" type="string" default="/">
  Directory path to list (e.g. `/src`).
</ParamField>

<ParamField query="recursive" type="boolean" default="false">
  When `true`, lists files recursively.
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

## Response

<ResponseField name="files" type="array">
  Array of file/directory entries.
</ResponseField>

<ResponseField name="files[].name" type="string">
  File or directory name.
</ResponseField>

<ResponseField name="files[].path" type="string">
  Full path within the sandbox.
</ResponseField>

<ResponseField name="files[].type" type="string">
  Entry type: `file` or `directory`.
</ResponseField>

<ResponseField name="files[].size" type="integer">
  File size in bytes (0 for directories).
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/cloud/sessions/ses_abc123/files?path=/src&recursive=true" \
  -H "Authorization: Bearer runtm_xxx"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/cloud/sessions/ses_abc123/files",
    headers={"Authorization": "Bearer runtm_xxx"},
    params={"path": "/src", "recursive": True},
)

for f in response.json()["files"]:
    print(f"{f['type']:9s} {f['path']} ({f['size']} bytes)")
```

```javascript JavaScript
const params = new URLSearchParams({ path: "/src", recursive: "true" });

const response = await fetch(
  `https://app.runtm.com/api/cloud/sessions/ses_abc123/files?${params}`,
  {
    headers: { "Authorization": "Bearer runtm_xxx" },
  }
);

const { files } = await response.json();
files.forEach((f) => console.log(`${f.type} ${f.path} (${f.size} bytes)`));
```
</RequestExample>

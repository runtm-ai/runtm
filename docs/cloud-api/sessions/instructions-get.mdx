---
title: "Get Session Instructions"
api: "GET /api/sessions/{session_id}/instructions"
description: "Retrieve per-session custom instructions"
---

Returns the custom instructions configured for this specific session. These instructions are passed to the coding agent as additional context.

**Required scope:** `context:read`

## Path Parameters

<ParamField path="session_id" type="string" required>
  The session ID (e.g. `ses_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

## Response

<ResponseField name="instructions" type="string">
  The custom instructions text, or `null` if none are set.
</ResponseField>

<ResponseField name="session_id" type="string">
  Session ID.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/sessions/ses_abc123/instructions" \
  -H "Authorization: Bearer runtm_xxx"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/sessions/ses_abc123/instructions",
    headers={"Authorization": "Bearer runtm_xxx"},
)

data = response.json()
if data["instructions"]:
    print(data["instructions"])
else:
    print("No custom instructions set")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/sessions/ses_abc123/instructions",
  {
    headers: { "Authorization": "Bearer runtm_xxx" },
  }
);

const { instructions } = await response.json();
console.log(instructions ?? "No custom instructions set");
```
</RequestExample>

```json 200
{
```

</ResponseExample>

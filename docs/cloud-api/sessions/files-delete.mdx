---
title: "Delete File"
api: "DELETE /api/sessions/{session_id}/file"
description: "Delete a file from the sandbox"
---

Deletes a file at the specified path in the sandbox.

**Required scope:** `sessions:write`

## Path Parameters

<ParamField path="session_id" type="string" required>
  The session ID (e.g. `ses_abc123`).
</ParamField>

## Query Parameters

<ParamField query="path" type="string" required>
  Path of the file to delete (e.g. `/src/old-file.ts`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

## Response

Returns `204 No Content` on success.

<RequestExample>
```bash cURL
curl -X DELETE "https://app.runtm.com/api/cloud/sessions/ses_abc123/file?path=/src/old-file.ts" \
  -H "Authorization: Bearer runtm_xxx"
```

```python Python
import requests

response = requests.delete(
    "https://app.runtm.com/api/cloud/sessions/ses_abc123/file",
    headers={"Authorization": "Bearer runtm_xxx"},
    params={"path": "/src/old-file.ts"},
)

assert response.status_code == 204
```

```javascript JavaScript
const params = new URLSearchParams({ path: "/src/old-file.ts" });

const response = await fetch(
  `https://app.runtm.com/api/cloud/sessions/ses_abc123/file?${params}`,
  {
    method: "DELETE",
    headers: { "Authorization": "Bearer runtm_xxx" },
  }
);

console.log(response.status); // 204
```
</RequestExample>

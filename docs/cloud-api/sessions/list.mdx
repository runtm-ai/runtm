---
title: "List Sessions"
api: "GET /api/sessions"
description: "List cloud sessions with pagination and filters"
---

Returns a paginated list of cloud sessions. Filter by state, agent, template, or visibility.

**Required scope:** `sessions:read`

## Query Parameters

<ParamField query="limit" type="integer" default="20">
  Number of results to return (1–100).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of results to skip for pagination.
</ParamField>

<ParamField query="state" type="string">
  Filter by session state: `active`, `paused`, `destroyed`.
</ParamField>

<ParamField query="agent" type="string">
  Filter by coding agent: `claude-code`, `codex`, `cursor`, `gemini`, etc.
</ParamField>

<ParamField query="template_id" type="string">
  Filter by template ID.
</ParamField>

<ParamField query="visibility" type="string">
  Filter by visibility: `private` or `team`.
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Scope to an organization's sessions.
</ParamField>

## Response

<ResponseField name="sessions" type="array">
  Array of session objects.
</ResponseField>

<ResponseField name="total" type="integer">
  Total number of matching sessions.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  Whether more results exist beyond the current page.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/cloud/sessions?limit=10&state=active" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "X-Organization-Id: org_abc123"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/cloud/sessions",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "X-Organization-Id": "org_abc123",
    },
    params={"limit": 10, "state": "active"},
)

data = response.json()
for s in data["sessions"]:
    print(f"{s['id']} - {s['name']} ({s['state']})")
```

```javascript JavaScript
const params = new URLSearchParams({ limit: "10", state: "active" });

    },
  }
);

const data = await response.json();
data.sessions.forEach((s) =>
  console.log(`${s.id} - ${s.name} (${s.state})`)
);
```

---
title: "Set Session Instructions"
api: "PUT /api/sessions/{session_id}/instructions"
description: "Set or update per-session custom instructions"
---

Sets or updates the custom instructions for a session. Instructions are passed to the coding agent as additional system context.

**Required scope:** `context:write`

## Path Parameters

<ParamField path="session_id" type="string" required>
  The session ID (e.g. `ses_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

## Body

<ParamField body="instructions" type="string" required>
  Custom instructions text. Pass an empty string to clear.
</ParamField>

## Response

<ResponseField name="session_id" type="string">
  Session ID.
</ResponseField>

<ResponseField name="instructions" type="string">
  Updated instructions text.
</ResponseField>

<RequestExample>
```bash cURL
curl -X PUT "https://app.runtm.com/api/cloud/sessions/ses_abc123/instructions" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "Content-Type: application/json" \
  -d '{"instructions": "Use TypeScript strict mode. Always write tests."}'
```

```python Python
import requests

response = requests.put(
    "https://app.runtm.com/api/cloud/sessions/ses_abc123/instructions",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "Content-Type": "application/json",
    },
    json={"instructions": "Use TypeScript strict mode. Always write tests."},
)

print(response.json()["instructions"])
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/cloud/sessions/ses_abc123/instructions",
  {
    method: "PUT",
    headers: {
      "Authorization": "Bearer runtm_xxx",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      instructions: "Use TypeScript strict mode. Always write tests.",
    }),
  }
);

const data = await response.json();
console.log(data.instructions);
```

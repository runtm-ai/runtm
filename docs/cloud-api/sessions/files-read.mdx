---
title: "Read File"
api: "GET /api/sessions/{session_id}/file"
description: "Read the contents of a file in the sandbox"
---

Returns the contents of a file at the specified path in the sandbox.

**Required scope:** `sessions:read`

## Path Parameters

<ParamField path="session_id" type="string" required>
  The session ID (e.g. `ses_abc123`).
</ParamField>

## Query Parameters

<ParamField query="path" type="string" required>
  Path to the file (e.g. `/src/index.ts`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

## Response

<ResponseField name="content" type="string">
  The file contents as a string.
</ResponseField>

<ResponseField name="path" type="string">
  Full path of the file.
</ResponseField>

<ResponseField name="size" type="integer">
  File size in bytes.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/cloud/sessions/ses_abc123/file?path=/src/index.ts" \
  -H "Authorization: Bearer runtm_xxx"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/cloud/sessions/ses_abc123/file",
    headers={"Authorization": "Bearer runtm_xxx"},
    params={"path": "/src/index.ts"},
)

data = response.json()
print(data["content"])
```

```javascript JavaScript
const params = new URLSearchParams({ path: "/src/index.ts" });

const response = await fetch(
  `https://app.runtm.com/api/cloud/sessions/ses_abc123/file?${params}`,
  {
    headers: { "Authorization": "Bearer runtm_xxx" },
  }
);

const { content } = await response.json();
console.log(content);
```
</RequestExample>

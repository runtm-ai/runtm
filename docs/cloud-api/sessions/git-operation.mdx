---
title: "Git Operation"
api: "POST /api/sessions/{session_id}/git"
description: "Execute a git operation in the sandbox"
---

Executes a git operation in the session's sandbox. Supports standard git operations like status, add, commit, push, pull, branch, checkout, diff, log, and create-pr.

**Required scope:** `sessions:write`

## Path Parameters

<ParamField path="session_id" type="string" required>
  The session ID (e.g. `ses_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

## Body

<ParamField body="operation" type="string" required>
  Git operation: `status`, `add`, `commit`, `push`, `pull`, `branch`, `checkout`, `diff`, `log`, `create-pr`.
</ParamField>

<ParamField body="args" type="object">
  Operation-specific arguments. For `commit`: `{message}`. For `checkout`: `{branch}`. For `create-pr`: `{title, body, base}`.
</ParamField>

## Response

<ResponseField name="operation" type="string">
  Operation that was executed.
</ResponseField>

<ResponseField name="result" type="object">
  Operation-specific result data.
</ResponseField>

<ResponseField name="success" type="boolean">
  Whether the operation succeeded.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/sessions/ses_abc123/git" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "operation": "commit",
    "args": {"message": "feat: add user validation"}
  }'
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/sessions/ses_abc123/git",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "Content-Type": "application/json",
    },
    json={
        "operation": "commit",
        "args": {"message": "feat: add user validation"},
    },
)

data = response.json()
print(f"{data['operation']}: {data['success']}")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/sessions/ses_abc123/git",
  {
    method: "POST",
    headers: {
      "Authorization": "Bearer runtm_xxx",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      operation: "commit",
      args: { message: "feat: add user validation" },
    }),
  }
);

const data = await response.json();
console.log(`${data.operation}: ${data.success}`);
```
</RequestExample>

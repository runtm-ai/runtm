---
title: "Get Session"
api: "GET /api/sessions/{session_id}"
description: "Retrieve a single cloud session by ID"
---

Returns the full session object including state, agent, sandbox URL, and timestamps.

**Required scope:** `sessions:read`

## Path Parameters

<ParamField path="session_id" type="string" required>
  The session ID (e.g. `ses_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Scope to an organization.
</ParamField>

## Response

<ResponseField name="id" type="string">
  Session ID.
</ResponseField>

<ResponseField name="name" type="string">
  Display name.
</ResponseField>

<ResponseField name="state" type="string">
  Session state: `active`, `paused`, or `destroyed`.
</ResponseField>

<ResponseField name="agent" type="string">
  Coding agent assigned to the session.
</ResponseField>

<ResponseField name="template_id" type="string | null">
  Template used to initialize the session.
</ResponseField>

<ResponseField name="sandbox_url" type="string">
  URL of the sandbox environment.
</ResponseField>

<ResponseField name="visibility" type="string">
  Session visibility: `private` or `team`.
</ResponseField>

<ResponseField name="user_id" type="string">
  Owner user ID.
</ResponseField>

<ResponseField name="organization_id" type="string | null">
  Organization the session belongs to.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 creation timestamp.
</ResponseField>

<ResponseField name="updated_at" type="string | null">
  ISO 8601 last update timestamp.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/sessions/ses_abc123" \
  -H "Authorization: Bearer runtm_xxx"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/sessions/ses_abc123",
    headers={"Authorization": "Bearer runtm_xxx"},
)

session = response.json()
print(f"{session['name']} — {session['state']}")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/sessions/ses_abc123",
  {
    headers: { "Authorization": "Bearer runtm_xxx" },
  }
);

const session = await response.json();
console.log(`${session.name} — ${session.state}`);
```
</RequestExample>

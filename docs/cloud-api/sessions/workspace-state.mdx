---
title: "Get Workspace State"
api: "GET /api/sessions/{session_id}/workspace-state"
description: "Retrieve workspace state including detected ports and processes"
---

Returns the current workspace state of a session, including detected ports, running processes, and file tree information.

**Required scope:** `sessions:read`

## Path Parameters

<ParamField path="session_id" type="string" required>
  The session ID (e.g. `ses_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Scope to an organization.
</ParamField>

## Response

<ResponseField name="detected_ports" type="array">
  Array of port objects currently listening in the sandbox.
</ResponseField>

<ResponseField name="detected_ports[].port" type="integer">
  Port number.
</ResponseField>

<ResponseField name="detected_ports[].process" type="string">
  Name of the process listening on this port.
</ResponseField>

<ResponseField name="running_processes" type="array">
  Array of running process descriptors.
</ResponseField>

<ResponseField name="file_tree" type="object">
  Summary of the workspace file tree.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/cloud/sessions/ses_abc123/workspace-state" \
  -H "Authorization: Bearer runtm_xxx"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/cloud/sessions/ses_abc123/workspace-state",
    headers={"Authorization": "Bearer runtm_xxx"},
)

state = response.json()
for port in state["detected_ports"]:
    print(f"Port {port['port']} - {port['process']}")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/cloud/sessions/ses_abc123/workspace-state",
  {
    headers: { "Authorization": "Bearer runtm_xxx" },
  }
);

const state = await response.json();
state.detected_ports.forEach((p) =>
  console.log(`Port ${p.port} - ${p.process}`)
);
```
</RequestExample>

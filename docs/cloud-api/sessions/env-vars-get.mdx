---
title: "Get Env Vars"
api: "GET /api/sessions/{session_id}/env-vars"
description: "Retrieve environment variables for a session"
---

Returns all environment variables configured for the session.

**Required scope:** `secrets:read`

## Path Parameters

<ParamField path="session_id" type="string" required>
  The session ID (e.g. `ses_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

## Response

<ResponseField name="env_vars" type="object">
  Key-value map of environment variables.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://app.runtm.com/api/sessions/ses_abc123/env-vars" \
  -H "Authorization: Bearer runtm_xxx"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/sessions/ses_abc123/env-vars",
    headers={"Authorization": "Bearer runtm_xxx"},
)

for key, value in response.json()["env_vars"].items():
    print(f"{key}={value}")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/sessions/ses_abc123/env-vars",
  {
    headers: { "Authorization": "Bearer runtm_xxx" },
  }
);

const { env_vars } = await response.json();
Object.entries(env_vars).forEach(([k, v]) => console.log(`${k}=${v}`));
```
</RequestExample>

<ResponseExample>
```json 200
{
  "env_vars": {
```

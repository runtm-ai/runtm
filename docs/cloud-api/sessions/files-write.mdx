---
title: "Write File"
api: "POST /api/sessions/{session_id}/file"
description: "Create or overwrite a file in the sandbox"
---

Creates or overwrites a file at the specified path in the sandbox.

**Required scope:** `sessions:write`

## Path Parameters

<ParamField path="session_id" type="string" required>
  The session ID (e.g. `ses_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

## Body

<ParamField body="path" type="string" required>
  Path where the file should be written (e.g. `/src/index.ts`).
</ParamField>

<ParamField body="content" type="string" required>
  File contents to write.
</ParamField>

## Response

<ResponseField name="path" type="string">
  Path of the written file.
</ResponseField>

<ResponseField name="size" type="integer">
  Size of the written file in bytes.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/cloud/sessions/ses_abc123/file" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "path": "/src/index.ts",
    "content": "console.log(\"hello world\");\n"
  }'
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/cloud/sessions/ses_abc123/file",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "Content-Type": "application/json",
    },
    json={
        "path": "/src/index.ts",
        "content": 'console.log("hello world");\n',
    },
)

print(response.json()["path"])
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/cloud/sessions/ses_abc123/file",
  {
    method: "POST",
    headers: {
      "Authorization": "Bearer runtm_xxx",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      path: "/src/index.ts",
      content: 'console.log("hello world");\n',
    }),
  }
);

const data = await response.json();
console.log(`Wrote ${data.size} bytes to ${data.path}`);
```
</RequestExample>

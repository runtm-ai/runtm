---
title: "Detect Env Vars"
api: "POST /api/sessions/{session_id}/detect-env-vars"
description: "Scan the project for required environment variables"
---

Scans the project files in the sandbox to detect required environment variables. Updates the detected env vars list for the session.

**Required scope:** `secrets:write`

## Path Parameters

<ParamField path="session_id" type="string" required>
  The session ID (e.g. `ses_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

## Response

<ResponseField name="detected_vars" type="array">
  Array of detected environment variable descriptors.
</ResponseField>

<ResponseField name="scanned_files" type="integer">
  Number of files scanned during detection.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/sessions/ses_abc123/detect-env-vars" \
  -H "Authorization: Bearer runtm_xxx"
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/sessions/ses_abc123/detect-env-vars",
    headers={"Authorization": "Bearer runtm_xxx"},
)

data = response.json()
print(f"Scanned {data['scanned_files']} files, found {len(data['detected_vars'])} vars")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/sessions/ses_abc123/detect-env-vars",
  {
    method: "POST",
    headers: { "Authorization": "Bearer runtm_xxx" },
  }

const data = await response.json();
console.log(`Scanned ${data.scanned_files} files, found ${data.detected_vars.length} vars`);
```

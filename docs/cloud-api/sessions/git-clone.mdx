---
title: "Clone Repository"
api: "POST /api/sessions/{session_id}/clone-repo"
description: "Clone a git repository into the sandbox"
---

Clones a git repository into the session's sandbox. Supports public repos and private repos when a GitHub App installation or user token is configured.

**Required scope:** `sessions:write`

## Path Parameters

<ParamField path="session_id" type="string" required>
  The session ID (e.g. `ses_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

## Body

<ParamField body="repo_url" type="string" required>
  Repository URL (e.g. `https://github.com/owner/repo`).
</ParamField>

<ParamField body="branch" type="string">
  Branch to clone. Defaults to the repository's default branch.
</ParamField>

## Response

<ResponseField name="session_id" type="string">
  Session ID.
</ResponseField>

<ResponseField name="repo_url" type="string">
  Cloned repository URL.
</ResponseField>

<ResponseField name="branch" type="string">
  Branch that was checked out.
</ResponseField>

<ResponseField name="path" type="string">
  Path where the repo was cloned in the sandbox.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/cloud/sessions/ses_abc123/clone-repo" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "Content-Type: application/json" \
  -d '{"repo_url": "https://github.com/owner/repo", "branch": "main"}'
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/cloud/sessions/ses_abc123/clone-repo",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "Content-Type": "application/json",
    },
    json={
        "repo_url": "https://github.com/owner/repo",
        "branch": "main",
    },
)

data = response.json()
print(f"Cloned to {data['path']} on branch {data['branch']}")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/cloud/sessions/ses_abc123/clone-repo",
  {
    method: "POST",
    headers: {
      "Authorization": "Bearer runtm_xxx",
      "Content-Type": "application/json",
    },

      branch: "main",
    }),
  }
);

const data = await response.json();
console.log(`Cloned to ${data.path} on branch ${data.branch}`);
```

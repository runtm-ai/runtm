---
title: "Update Visibility"
api: "POST /api/sessions/{session_id}/visibility"
description: "Change a session's visibility between private and team"
---

Updates the visibility of a session. `private` sessions are only visible to the owner; `team` sessions are visible to all organization members.

**Required scope:** `sessions:write`

## Path Parameters

<ParamField path="session_id" type="string" required>
  The session ID (e.g. `ses_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Scope to an organization.
</ParamField>

## Body

<ParamField body="visibility" type="string" required>
  New visibility: `private` or `team`.
</ParamField>

## Response

Returns the updated session object.

<ResponseField name="id" type="string">
  Session ID.
</ResponseField>

<ResponseField name="visibility" type="string">
  Updated visibility setting.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/cloud/sessions/ses_abc123/visibility" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "Content-Type: application/json" \
  -d '{"visibility": "team"}'
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/cloud/sessions/ses_abc123/visibility",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "Content-Type": "application/json",
    },
    json={"visibility": "team"},
)

print(response.json()["visibility"])
```


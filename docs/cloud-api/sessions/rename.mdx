---
title: "Rename Session"
api: "PATCH /api/sessions/{session_id}/name"
description: "Update the display name of a session"
---

Updates the display name of an existing session.

**Required scope:** `sessions:write`

## Path Parameters

<ParamField path="session_id" type="string" required>
  The session ID (e.g. `ses_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

<ParamField header="X-Organization-Id" type="string">
  Scope to an organization.
</ParamField>

## Body

<ParamField body="name" type="string" required>
  New display name for the session.
</ParamField>

## Response

Returns the updated session object.

<ResponseField name="id" type="string">
  Session ID.
</ResponseField>

<ResponseField name="name" type="string">
  Updated display name.
</ResponseField>

<RequestExample>
```bash cURL
curl -X PATCH "https://app.runtm.com/api/cloud/sessions/ses_abc123/name" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "Content-Type: application/json" \
  -d '{"name": "Auth service rewrite"}'
```

```python Python
import requests

response = requests.patch(
    "https://app.runtm.com/api/cloud/sessions/ses_abc123/name",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "Content-Type": "application/json",
    },
    json={"name": "Auth service rewrite"},
)

print(response.json()["name"])
```

```javascript JavaScript
const response = await fetch(
```

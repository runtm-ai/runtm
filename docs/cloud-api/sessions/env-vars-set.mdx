---
title: "Set Env Vars"
api: "PUT /api/sessions/{session_id}/env-vars"
description: "Set environment variables for a session"
---

Sets environment variables for the session. Replaces all existing env vars with the provided values.

**Required scope:** `secrets:write`

## Path Parameters

<ParamField path="session_id" type="string" required>
  The session ID (e.g. `ses_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

## Body

<ParamField body="env_vars" type="object" required>
  Key-value map of environment variables to set.
</ParamField>

## Response

<ResponseField name="env_vars" type="object">
  Updated key-value map of environment variables.
</ResponseField>

<RequestExample>
```bash cURL
curl -X PUT "https://app.runtm.com/api/sessions/ses_abc123/env-vars" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "env_vars": {
      "NODE_ENV": "production",
      "API_KEY": "sk-new-key"
    }
  }'
```

```python Python
import requests

response = requests.put(
    "https://app.runtm.com/api/sessions/ses_abc123/env-vars",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "Content-Type": "application/json",
    },
    json={
        "env_vars": {
            "NODE_ENV": "production",
            "API_KEY": "sk-new-key",
        }
    },
)

print(response.json()["env_vars"])
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/sessions/ses_abc123/env-vars",
  {
    method: "PUT",
    headers: {
      "Authorization": "Bearer runtm_xxx",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      env_vars: {
        NODE_ENV: "production",
        API_KEY: "sk-new-key",
      },
    }),
  }
);

const { env_vars } = await response.json();
console.log(env_vars);
```

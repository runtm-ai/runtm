---
title: "Git Sync"
api: "POST /api/sessions/{session_id}/sync-git"
description: "Sync local changes with the remote repository"
---

Synchronizes the sandbox's local git changes with the remote repository. Performs a fetch, rebase, and push to ensure the local and remote branches are in sync.

**Required scope:** `sessions:write`

## Path Parameters

<ParamField path="session_id" type="string" required>
  The session ID (e.g. `ses_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

## Response

<ResponseField name="session_id" type="string">
  Session ID.
</ResponseField>

<ResponseField name="synced" type="boolean">
  Whether the sync completed successfully.
</ResponseField>

<ResponseField name="ahead" type="integer">
  Number of commits ahead of remote after sync.
</ResponseField>

<ResponseField name="behind" type="integer">
  Number of commits behind remote after sync.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/sessions/ses_abc123/sync-git" \
  -H "Authorization: Bearer runtm_xxx"
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/sessions/ses_abc123/sync-git",
    headers={"Authorization": "Bearer runtm_xxx"},
)

data = response.json()
print(f"Synced: {data['synced']} (ahead: {data['ahead']}, behind: {data['behind']})")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/sessions/ses_abc123/sync-git",
  {
    method: "POST",
    headers: { "Authorization": "Bearer runtm_xxx" },
  }
);

const data = await response.json();
console.log(`Synced: ${data.synced} (ahead: ${data.ahead}, behind: ${data.behind})`);
```
</RequestExample>

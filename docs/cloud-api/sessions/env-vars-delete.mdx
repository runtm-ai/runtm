---
title: "Delete Env Var"
api: "DELETE /api/sessions/{session_id}/env-vars/{key}"
description: "Remove a single environment variable from a session"
---

Deletes a single environment variable from the session by key name.

**Required scope:** `secrets:write`

## Path Parameters

<ParamField path="session_id" type="string" required>
  The session ID (e.g. `ses_abc123`).
</ParamField>

<ParamField path="key" type="string" required>
  The environment variable key to delete (e.g. `API_KEY`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

## Response

Returns `204 No Content` on success.

<RequestExample>
```bash cURL
curl -X DELETE "https://app.runtm.com/api/sessions/ses_abc123/env-vars/API_KEY" \
  -H "Authorization: Bearer runtm_xxx"
```

```python Python
import requests

response = requests.delete(
    "https://app.runtm.com/api/sessions/ses_abc123/env-vars/API_KEY",
    headers={"Authorization": "Bearer runtm_xxx"},
)

assert response.status_code == 204
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/sessions/ses_abc123/env-vars/API_KEY",
  {
    method: "DELETE",
    headers: { "Authorization": "Bearer runtm_xxx" },
  }
);

console.log(response.status); // 204
```
</RequestExample>

<ResponseExample>


</ResponseExample>

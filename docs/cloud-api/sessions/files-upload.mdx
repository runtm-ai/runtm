---
title: "Upload File"
api: "POST /api/sessions/{session_id}/file/upload"
description: "Upload a file to the sandbox via multipart form"
---

Uploads a file to the sandbox using multipart form data.

**Required scope:** `sessions:write`

## Path Parameters

<ParamField path="session_id" type="string" required>
  The session ID (e.g. `ses_abc123`).
</ParamField>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Example: `Bearer runtm_xxx`
</ParamField>

## Body (multipart/form-data)

<ParamField body="file" type="file" required>
  The file to upload.
</ParamField>

<ParamField body="path" type="string" required>
  Destination path in the sandbox (e.g. `/src/data.json`).
</ParamField>

## Response

<ResponseField name="path" type="string">
  Path where the file was written.
</ResponseField>

<ResponseField name="size" type="integer">
  Size of the uploaded file in bytes.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/sessions/ses_abc123/file/upload" \
  -H "Authorization: Bearer runtm_xxx" \
  -F "file=@./data.json" \
  -F "path=/src/data.json"
```

```python Python
import requests

with open("data.json", "rb") as f:
    response = requests.post(
        "https://app.runtm.com/api/sessions/ses_abc123/file/upload",
        headers={"Authorization": "Bearer runtm_xxx"},
        files={"file": f},
        data={"path": "/src/data.json"},
    )

data = response.json()
print(f"Uploaded {data['size']} bytes to {data['path']}")
```

```javascript JavaScript
const formData = new FormData();

```

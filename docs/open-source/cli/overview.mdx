# CLI Overview

The Runtime CLI is how you spin up sandboxes and deploy your agent's work.

## Installation

<CodeGroup>

```bash uv (recommended)
uv tool install runtm
```

```bash pipx
pipx install runtm
```

```bash pip
pip install runtm
```

</CodeGroup>

## Upgrading

<CodeGroup>

```bash uv
uv tool upgrade runtm
```

```bash pipx
pipx upgrade runtm
```

```bash pip
pip install --upgrade runtm
```

</CodeGroup>

## Global Options

| Option | Description |
|--------|-------------|
| `--help` | Show help for any command |
| `--version` | Show CLI version |

## Configuration

The CLI stores configuration in `~/.runtm/config.yaml`:

```yaml
api_url: https://app.runtm.com/api
```

### Environment Variables

| Variable | Description |
|----------|-------------|
| `RUNTM_API_URL` | API endpoint (for self-hosting) |
| `RUNTM_API_KEY` | API key (alternative to `runtm login`) |

## Authentication Storage

The CLI stores your API key securely:

1. **File**: `~/.runtm/credentials` (mode 600)
2. **Keychain**: System keychain (if `keyring` package installed)
3. **Environment**: `RUNTM_API_KEY` variable

Check your setup with:

```bash
runtm doctor
```

## Exit Codes

| Code | Meaning |
|------|---------|
| `0` | Success |
| `1` | General error |
| `2` | Invalid arguments |

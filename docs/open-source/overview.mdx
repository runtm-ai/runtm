Runtime's core is open source. You can self-host the control plane, use the CLI to manage sandboxes locally, and interact with the OSS deployment API directly.

<Info>
Most users should start with the [hosted platform documentation](/) and the [API Reference](/cloud-api/overview). The open-source docs here are for teams that want to run Runtime on their own infrastructure or contribute to the project.
</Info>

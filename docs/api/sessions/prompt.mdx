---
title: "Send Prompt"
api: "POST /v0/sessions/{session_id}/prompt"
description: "Send a prompt to a running session and stream the response via SSE"
---

Send a prompt to a running session and receive the agent's output as a Server-Sent Events (SSE) stream. The session must be in the `running` state.

Uses durable execution that survives client disconnects — if you reconnect while a prompt is running, you receive the remaining events from where it left off.

## Path Parameters

<ParamField path="session_id" type="string" required>
  Session UUID
</ParamField>

## Request Body

<ParamField body="prompt" type="string" required>
  The prompt to send to the agent (up to 100,000 characters)
</ParamField>

<ParamField body="model" type="string">
  Model override: `sonnet` (default), `opus`, `haiku`, or `opusplan`
</ParamField>

<ParamField body="continue_session" type="string">
  Claude Code session ID for conversation continuity across prompts
</ParamField>

<ParamField body="plan_mode" type="boolean" default="false">
  When `true`, the agent analyzes without making code changes
</ParamField>

## Response

Returns a `text/event-stream` (SSE) response. Each event has a `type` and `data` field:

| Event Type | Description |
|------------|-------------|
| `output` | Agent output chunk (text, code, etc.) |
| `result` | Final result with summary and cost metadata |
| `error` | Error during prompt execution |
| `done` | Stream complete |

<RequestExample>
```bash cURL
curl -N -H "Authorization: Bearer runtm_xxx" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Add input validation to all endpoints"}' \
  "https://app.runtm.com/api/v0/sessions/a1b2c3d4-e5f6-7890-abcd-ef1234567890/prompt"
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/v0/sessions/a1b2c3d4-e5f6-7890-abcd-ef1234567890/prompt",
    headers={"Authorization": "Bearer runtm_xxx"},
    json={"prompt": "Add input validation to all endpoints"},
    stream=True,
)

for line in response.iter_lines():
    if line:
        decoded = line.decode("utf-8")
        if decoded.startswith("data: "):
            print(decoded[6:])
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/v0/sessions/a1b2c3d4-e5f6-7890-abcd-ef1234567890/prompt",
  {
    method: "POST",
    headers: {
      "Authorization": "Bearer runtm_xxx",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      prompt: "Add input validation to all endpoints",
    }),
  }
);

const reader = response.body.getReader();
const decoder = new TextDecoder();

while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  console.log(decoder.decode(value));
}
```
</RequestExample>

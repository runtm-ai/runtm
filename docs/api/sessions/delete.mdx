---
title: "Delete Session"
api: "DELETE /v0/sessions/{session_id}"
description: "Permanently destroy a session and its sandbox"
---

Permanently destroy a session and clean up the associated sandbox. This is irreversible — all files, environment, and state are deleted.

## Path Parameters

<ParamField path="session_id" type="string" required>
  Session UUID
</ParamField>

## Response

<ResponseField name="id" type="string">
  The destroyed session's identifier
</ResponseField>

<ResponseField name="destroyed_at" type="string">
  ISO 8601 timestamp of destruction
</ResponseField>

<ResponseField name="message" type="string">
  Confirmation message
</ResponseField>

<RequestExample>
```bash cURL
curl -X DELETE "https://app.runtm.com/api/v0/sessions/a1b2c3d4-e5f6-7890-abcd-ef1234567890" \
  -H "Authorization: Bearer runtm_xxx"
```

```python Python
import requests

response = requests.delete(
    "https://app.runtm.com/api/v0/sessions/a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    headers={"Authorization": "Bearer runtm_xxx"},
)

print(response.json()["message"])
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/v0/sessions/a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  {
    method: "DELETE",
    headers: { "Authorization": "Bearer runtm_xxx" },
  }

console.log(result.message);
```
</RequestExample>

---
title: "Create Session"
api: "POST /v0/sessions"
description: "Create a new sandbox session for programmatic agent workflows"
---

Create a new cloud sandbox session. The session provisions an isolated E2B environment with your chosen coding agent ready to use.

Requires API key authentication with `sessions` scope.

## Request Body

<ParamField body="template" type="string">
  Project template to scaffold: `web-app`, `backend-service`, `static-site`, or `docker`
</ParamField>

<ParamField body="agent" type="string" default="claude-code">
  Coding agent to use: `claude-code`, `codex`, `github-copilot`, or `opencode`
</ParamField>

<ParamField body="mode" type="string" default="autopilot">
  Session mode: `autopilot` (agent auto-approves actions) or `interactive` (agent may ask questions)
</ParamField>

<ParamField body="source" type="string">
  Session source identifier: `api` for programmatic use, `agents` for mission control
</ParamField>

<ParamField body="on_complete" type="string" default="pause">
  Lifecycle action when a prompt completes: `pause` (default), `destroy`, or `keep_alive`
</ParamField>

<ParamField body="ttl_minutes" type="integer">
  Maximum session lifetime in minutes (1-1440). Default: 60 for API-created sessions
</ParamField>

<ParamField body="github_repo" type="object">
  GitHub repository metadata for cloning into the sandbox. Fields: `full_name`, `size_kb`, `requires_docker`, `has_docker_compose`, `is_monorepo`
</ParamField>

## Response

<ResponseField name="id" type="string">
  Unique session identifier (UUID)
</ResponseField>

<ResponseField name="state" type="string">
  Initial session state (usually `provisioning`, then `running`)
</ResponseField>

<ResponseField name="agent" type="string">
  The coding agent configured for this session
</ResponseField>

<ResponseField name="template" type="string">
  Template used, if any
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp
</ResponseField>

<ResponseField name="expires_at" type="string">
  ISO 8601 timestamp when the session will expire (based on TTL)
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://app.runtm.com/api/v0/sessions" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "template": "backend-service",
    "agent": "claude-code",
    "mode": "autopilot"
  }'
```

```python Python
import requests

response = requests.post(
    "https://app.runtm.com/api/v0/sessions",
    headers={"Authorization": "Bearer runtm_xxx"},
    json={
        "template": "backend-service",
        "agent": "claude-code",
        "mode": "autopilot",
    },
)

session = response.json()
print(f"Session {session['id']} created (state: {session['state']})")
```

```javascript JavaScript
const response = await fetch(
  "https://app.runtm.com/api/v0/sessions",
  {
    method: "POST",
    headers: {
      "Authorization": "Bearer runtm_xxx",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      template: "backend-service",
      agent: "claude-code",
      mode: "autopilot",
    }),
  }
);

const session = await response.json();
console.log(`Session ${session.id} created (state: ${session.state})`);
```

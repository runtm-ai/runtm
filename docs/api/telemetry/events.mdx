---
title: "Events"
api: "GET /v0/telemetry/events"
description: "Query telemetry events from your deployments"
---

List telemetry events — timestamped occurrences like deploy completions, errors, or configuration changes.

Requires `read` scope.

## Query Parameters

<ParamField query="name" type="string">
  Filter by event name (e.g., `deploy.completed`, `build.failed`)
</ParamField>

<ParamField query="deployment" type="string">
  Filter by deployment ID
</ParamField>

<ParamField query="limit" type="integer" default="100">
  Maximum results (1–500)
</ParamField>

<RequestExample>
```bash cURL
curl -H "Authorization: Bearer runtm_xxx" \
  "https://app.runtm.com/api/v0/telemetry/events?name=deploy.completed&limit=20"
```

```bash cURL — Filter by deployment
curl -H "Authorization: Bearer runtm_xxx" \
  "https://app.runtm.com/api/v0/telemetry/events?deployment=dep_abc123"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/api/v0/telemetry/events",
    headers={"Authorization": "Bearer runtm_xxx"},
    params={"name": "deploy.completed", "limit": 20},
)

for event in response.json().get("events", []):
    print(f"[{event['timestamp']}] {event['name']}: {event['attributes']}")
```
</RequestExample>

## Prerequisites

- Python 3.9+
- A [Runtm account](https://app.runtm.com)

## Install the CLI

<CodeGroup>

```bash uv (recommended)
uv tool install runtm
```

```bash pipx
pipx install runtm
```

```bash pip
pip install runtm
```

</CodeGroup>

Verify installation:

```bash
runtm version
```

## Spin up a sandbox

```bash
runtm init
```

This creates an isolated workspace for your agent to build in. You'll be prompted to authenticate if you haven't already.

<Tip>
Start from scratch or pick a template—your agent can build anything.
</Tip>

## Test locally

```bash
runtm run
```

The CLI detects your runtime and starts the right dev server.

## Deploy

```bash
runtm deploy
```

First deploy takes 2-3 minutes. Subsequent deploys are faster.

```
✓ Validated project
✓ Created artifact (2.1 MB)
✓ Building...
✓ Deploying...

🚀 Deployed!

   URL: https://my-app-xyz123.fly.dev
   ID:  dep_abc123xyz
```

## View logs

```bash
runtm logs dep_abc123xyz
```

Filter by type:

```bash
runtm logs dep_abc123xyz --type build
runtm logs dep_abc123xyz --type runtime
```

Your agent can use these logs to debug and fix issues.

## Quick Start via API

Prefer to use the API directly? Launch a background agent with a single request:

```bash
curl -X POST "https://app.runtm.com/api/v0/sessions/launch" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Build a REST API with health check and CRUD endpoints",
    "template": "backend-service",
    "agent": "claude-code"
  }'
```

Then poll for results:

```bash
curl -H "Authorization: Bearer runtm_xxx" \
  "https://app.runtm.com/api/v0/sessions/{session_id}"
```

See the [Background Agents guide](/cloud/background-agents) for the full walkthrough.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Command not found">
    Ensure the CLI is in your PATH:
    ```bash
    uv tool install runtm --force
    ```
  </Accordion>
  <Accordion title="Authentication failed">
    Check your setup:
    ```bash
    runtm doctor
    ```
  </Accordion>
  <Accordion title="Lockfile error">
    Auto-fix:
    ```bash
    runtm deploy --yes
    ```
  </Accordion>
</AccordionGroup>

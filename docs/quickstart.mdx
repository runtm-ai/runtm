## Prerequisites

- A [Runtime account](https://app.runtm.com)
- An API key (created in **Settings > API Keys**)

## 1. Create an API key

Sign in at [app.runtm.com](https://app.runtm.com), go to **Settings > API Keys**, and click **Create key**.

Pick the **Session automation** preset for this tutorial. Copy the secret immediately - it is shown only once.

<Warning>
Store the key in a secret manager (1Password, Doppler, GitHub Actions secrets). Runtime does not store the raw key and cannot recover it.
</Warning>

## 2. Verify the key

<CodeGroup>

```bash cURL
curl https://app.runtm.com/auth/verify \
  -H "Authorization: Bearer runtm_xxx"
```

```python Python
import requests

response = requests.get(
    "https://app.runtm.com/auth/verify",
    headers={"Authorization": "Bearer runtm_xxx"},
)
print(response.json())
```

```javascript JavaScript
const response = await fetch("https://app.runtm.com/auth/verify", {
  headers: { Authorization: "Bearer runtm_xxx" },
});
console.log(await response.json());
```

</CodeGroup>

You should see your key's scopes and metadata:

```json
{
  "valid": true,
  "key_id": "1f3c5e2a-...",
  "name": "my-key",
  "scopes": ["sessions:read", "sessions:write", "sessions:prompt", "context:read"]
}
```

## 3. Create a session

<CodeGroup>

```bash cURL
curl -X POST https://app.runtm.com/api/sessions \
  -H "Authorization: Bearer runtm_xxx" \
  -H "Content-Type: application/json" \
  -d '{"name": "my-first-session"}'
```

```python Python
response = requests.post(
    "https://app.runtm.com/api/sessions",
    headers={
        "Authorization": "Bearer runtm_xxx",
        "Content-Type": "application/json",
    },
    json={"name": "my-first-session"},
)
session = response.json()
print(f"Session ID: {session['id']}, State: {session['state']}")
```

```javascript JavaScript
const response = await fetch("https://app.runtm.com/api/sessions", {
  method: "POST",
  headers: {
    Authorization: "Bearer runtm_xxx",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ name: "my-first-session" }),
});
const session = await response.json();
console.log(`Session ID: ${session.id}, State: ${session.state}`);
```

</CodeGroup>

The session starts in `creating` state. Poll `GET /api/sessions/{id}` until it becomes `running`, or call `POST /api/sessions/{id}/start` to wait for it.

## 4. Send a prompt

Once the session is `running`:

<CodeGroup>

```bash cURL
curl -X POST "https://app.runtm.com/api/sessions/${SESSION_ID}/prompt" \
  -H "Authorization: Bearer runtm_xxx" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Create a simple Express.js hello world server"}'
```

```python Python
response = requests.post(
    f"https://app.runtm.com/api/sessions/{session_id}/prompt",
    headers={"Authorization": "Bearer runtm_xxx"},
    json={"prompt": "Create a simple Express.js hello world server"},
)
print(response.json())
```

```javascript JavaScript
const response = await fetch(
  `https://app.runtm.com/api/sessions/${sessionId}/prompt`,
  {
    method: "POST",
    headers: {
      Authorization: "Bearer runtm_xxx",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      prompt: "Create a simple Express.js hello world server",
    }),
  }
);
console.log(await response.json());
```

</CodeGroup>

## 5. Check the workspace

List the files the agent created:

```bash
curl "https://app.runtm.com/api/sessions/${SESSION_ID}/files?path=/" \
  -H "Authorization: Bearer runtm_xxx"
```
